# CSAP 인증 참고 자료

클라우드 보안인증(CSAP) **하등급 SaaS** 준비에 쓰는 통제항목 해설서 정리본과 산출물 양식이다.

innopam/gis-sass 저장소의 `docs/90.관리/산출물/CSAP/` 와 `docs/CSAP/양식/` 을 **복사**한 것이다.

- 복사 시점: 2026-10-20, gis-sass 커밋 `85a96ba`
- gis-sass 쪽 원본은 그대로 두었다. 두 곳 중 어느 쪽을 기준으로 고칠지는 아직 정하지 않았다.
  고치기 전에 상대 쪽과 어긋나지 않는지 확인한다.

## 구조

```text
docs/CSAP/
├── README.md                     이 문서
├── .markdownlint-cli2.jsonc      외부 자료라 줄 길이·첫 줄 제목·HTML 규칙을 끈 설정 (gis-sass 에서 가져옴)
├── 해설서/
│   ├── 원본/                     해설서 통제항목 30개를 관리적·기술적·공공기관으로 나눠 정리
│   └── 하등급-SaaS/              같은 30개를 하등급 SaaS 기준으로 요약 (01. 관리적 8 · 02. 기술적 11 · 03. 공공기관 11)
└── 양식/
    ├── 하등급-SaaS/              통제항목 30개 폴더, 산출물 양식 188건 (파일 이름 `NN. <문서>-양식_v0.0.1.md`)
    ├── 비기술 양식 작성 TODO.md   개발·운영 지식 없이 채울 수 있는 양식 47개 목록
    └── 양식 작성 팁.html         양식 작성 요령
```

- 양식 파일은 각자 근거가 되는 `해설서/하등급-SaaS/` 항목을 상대 링크로 가리킨다.
  `하등급-SaaS/` 해설은 `원본/` 의 같은 항목을 가리킨다. 폴더 구조를 바꾸면 이 링크가 깨진다.
- 해설서 정리본의 front matter 는 `source: 클라우드컴퓨팅서비스 보안인증기준 해설서` 만 적고
  판·발행일이 없다. 기준 문서의 판은 gis-sass ADR
  `docs/01.개발/ADRs/deployment/2026-09-26.02-csap-인증-범위와-운영-타깃-재확인.md` 에서 다룬다.

## 관련 작업

제출 산출물(WBS 32–35: CSAP 인증 신청서, 보안 요구사항 반영 결과서, 보안 운영체계 구성도, CSAP 인증 대응 문서)과
그 계획(M011, T077–T081, T098)은 gis-sass 에 있다. 여기에는 참고 자료만 둔다.
