## 1. 목적과 사용 방법

- 인증 범위 내 모든 클라우드 시스템(VM, DBMS, 네트워크, 응용프로그램, 정보보호시스템, IaaS/PaaS 콘솔 등)에 사용자 인증절차가 수립·적용되어 있음을 시스템 단위로 보이고, 양식 02. 사용자 인증 관리 절차 6항의 최소 기준과 실제 설정값을 대조한다.
- 시스템 도입·변경 시 {{5}}영업일 이내에 행을 추가·갱신하고, 반기 점검(양식 05) 결과를 반영해 새 버전을 승인받는다.
- 기준을 충족하지 못하는 항목은 4항 예외 승인 목록에 등록하고 예외 번호를 2항의 해당 행에 적는다. 예외 승인 없이 미충족 상태로 두지 않는다.

## 7. 현행화 규칙

- 시스템 도입·폐기·인증 설정 변경이 승인되면 {{5}}영업일 이내에 본 현황을 갱신하고 버전을 올린다.
- 반기 1회 이상 양식 05. 사용자 인증 통제 점검 기록으로 6항 자료와 전면 대조하고, 결과를 반영한 버전을 승인받는다.
- 제공자가 콘솔 인증 기능을 변경(다중 인증 방식 추가·종료, 세션 정책 변경 등)하면 5항과 해당 행을 갱신한다.
- 모든 버전은 {{3}}년 이상 보관하여 특정 시점의 인증 설정을 확인할 수 있게 한다.
