## 1. 개요

- 목적: 장애·재해·침해사고로 {{서비스명}}의 시스템·데이터가 손상되었을 때, 담당자가 본 절차서만으로 복구를 수행할 수 있도록 시스템별 상세 복구 절차를 정한다.
- 적용 범위: 양식 02. 정보자산 및 백업 대상 목록의 백업 대상 자산 전체와 양식 03. 네트워크 구성도의 구성요소 전체
- 사용 시점: 시스템 장애, 데이터 손상·유실, 침해사고(랜섬웨어 등), 가용영역·리전 장애, 재해 복구 선언 시
- 작성 원칙: 각 절차는 수행 명령·콘솔 메뉴 수준까지 구체적으로 적고, 복원 시험(양식 06)으로 검증한 내용만 확정한다. 담당자 부재 시에도 수행할 수 있어야 한다.

## 7. 복구 후 확인

복구 완료를 선언하기 전에 다음을 모두 확인하고 결과를 기록한다.

- [ ] 핵심 기능 점검 목록({{로그인, 주요 업무 기능, API}})이 모두 정상이다.
- [ ] 복원 데이터의 정합성(건수·최신성)이 확인 기준을 충족한다.
- [ ] 보안 설정(보안 그룹, IAM, 웹 방화벽, 접근제어)이 복구 전 승인된 상태와 일치하며, 복구 과정에서 임시로 완화한 설정을 원복했다.
- [ ] 로그 수집·모니터링·백업 작업이 재개되었다.
- [ ] 복구 결과와 소요 시간(RTO·RPO 달성 여부)을 {{장애 보고서 / 침해사고 보고서}}에 기록했다.
- [ ] 이용 기관 통지가 필요한 경우 통지를 완료했다(14.1.4 사고 및 장애 대응 기준).
