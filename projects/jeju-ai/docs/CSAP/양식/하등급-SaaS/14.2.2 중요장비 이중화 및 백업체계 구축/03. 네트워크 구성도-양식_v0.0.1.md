## 1. 서비스 네트워크 구성도

{{서비스명}}의 현행 구성을 그린다. 예시 다이어그램의 노드·연결을 실제 구성으로 바꾸고, 백업 저장소와 백업 흐름이 드러나게 그린다.

```mermaid
flowchart TD
    USER["이용 기관 사용자"]
    NET["인터넷 / 전용망({{국가정보통신망 등}})"]
    WAF["웹 방화벽"]
    LB["로드밸런서"]

    subgraph REGION["{{IaaS 제공자명}} 국내 리전 {{리전명}}"]
        subgraph AZ1["가용영역 A"]
            WEB1["웹·API 서버 #1"]
            DB1["운영 DB(주)"]
        end
        subgraph AZ2["가용영역 B"]
            WEB2["웹·API 서버 #2"]
            DB2["운영 DB(대기)"]
        end
        OBJ["객체 스토리지(서비스 파일)"]
        BKUP["백업 저장소(스냅샷·DB 백업)"]
    end

    DRSITE["{{DR 환경: 다른 국내 리전 / DR 서비스(양식 05)}}"]

    USER --> NET --> WAF --> LB
    LB --> WEB1
    LB --> WEB2
    WEB1 --> DB1
    WEB2 --> DB1
    DB1 -. "복제" .-> DB2
    WEB1 --> OBJ
    WEB2 --> OBJ
    DB1 -. "백업" .-> BKUP
    WEB1 -. "이미지 백업" .-> BKUP
    OBJ -. "복제·버전 관리" .-> BKUP
    BKUP -. "리전 간 복제" .-> DRSITE
```

- 실선은 서비스 트래픽, 점선은 복제·백업 흐름을 뜻한다.
- 관리용 접근 경로(VPN, 접근제어 시스템)와 정보보호시스템은 {{별도 구성도 문서번호}}에 상세를 두고, 본 구성도에는 복구·백업과 관련된 요소를 빠짐없이 표기한다.
