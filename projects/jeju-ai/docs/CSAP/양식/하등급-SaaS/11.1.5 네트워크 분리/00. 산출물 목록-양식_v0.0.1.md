## 2. 권장 작성 순서

1. 01 네트워크 분리 관리 지침: 분리 원칙, 영역 구분, 인터넷 접근 제한·자료전송·우회 경로 통제, 검토 주기를 정하고 정보보호 최고책임자 승인을 받아요.
2. 02 네트워크 영역별 분리 기준: 영역별 배치 기준과 분리 구현 수단, 환경 분리·테넌트 분리 기준을 정해요. 영역 명칭은 9.1.5 구성도와 동일하게 맞춰요.
3. 03 네트워크 분리 구성도: 클라우드 콘솔의 계정·VPC·서브넷·연계 구성을 조회해 영역 단위 구성도와 접근통제 요약을 작성해요.
4. 04 네트워크 분리 정책 준수 검토서: 분기마다(그리고 구조 변경 시) 실제 구성과 대조 검토하고 기록을 누적해요.
5. 05 증적 수집 점검표: 심사 전에 콘솔 설정·시험 결과 화면을 수집해 보관 위치를 기록해요.

## 3. 심사 대비 체크리스트

- [ ] 네트워크 영역(DMZ, 내부 - 앱, 내부 - DB, 관리망, 개발·시험)을 분리 기준과 함께 문서화했고, 실제 클라우드 구성과 일치한다.
- [ ] 운영 네트워크와 개발·시험 네트워크가 계정 또는 VPC 단위로 분리되어 있고, 동일 VPC 내 서브넷 구분만으로 분리하지 않았다.
- [ ] 개발·시험 환경과 운영 환경 간 피어링·라우팅이 없고, 개발 서버에서 운영 DB로 접속할 수 없다.
- [ ] 이용자의 중요정보가 저장된 DB가 프라이빗 서브넷(내부 - DB)에만 있고, 퍼블릭 서브넷 배치·공인 IP 할당이 없다.
- [ ] DMZ 공개서버를 경유한 내부망 접근이 통제되고, DMZ에서 DB로 직접 향하는 경로가 없다.
- [ ] DMZ·내부망 서버에서 인터넷으로의 불필요한 직접 접속이 차단되고, 아웃바운드는 NAT·프록시 경유 허용 목적지로만 한정된다.
- [ ] 클라우드 시스템 운영 인력의 접속 경로(관리망)가 분리되어 있고 VPN·배스천(다중 인증)을 경유해서만 접근한다.
- [ ] 외부 접근이 필요 없는 운영자용 서비스 관리 포털이 이용자용 포털과 분리되어 내부 네트워크에 있다.
- [ ] 이용자 간 서비스 영역이 응용·DB 계층에서 논리적으로 분리되어 있고 격리 시험 기록이 있다.
- [ ] 망간 자료전송 통제 방안이 있고 승인·전송 기록이 보관된다.
- [ ] 우회 경로(미등재 공인 IP, 임의 터널·피어링, 배스천 미경유 관리 포트)를 모니터링하고 차단·조치 기록이 있다.
- [ ] 네트워크 분리 정책 준수 여부를 분기 1회 이상, 구조 변경 시 검토한 기록(04)이 누적되어 있다.
- [ ] 물리 네트워크·하이퍼바이저 격리는 제공자 책임임을 책임공유모델로 명시하고 제공자 CSAP 인증서·계약 사본을 보관하고 있다.

## 4. 관련 산출물(다른 항목)

- 9.1.5 공개서버 보안: 공개서버 네트워크 및 시스템 구성도와 영역 명칭·대역·보안 그룹 체계를 공유해요. 서버·규칙 단위 통신 허용 매트릭스는 9.1.5 양식 03에서 관리해요.
- 11.1.4 네트워크 암호화: 분리된 영역 간·외부 구간 통신의 암호화 기준을 맞춰요.
- 10.1.2 접근기록 관리: 흐름 로그·네트워크 구성 변경 감사 로그를 접근기록 관리 대상에 포함해요.
- 2.1.2 주요 직무자 지정 및 감독: 네트워크 구성 변경 권한 보유자(네트워크 관리자)를 주요 직무자 목록에 등재해요.
- 13.2.1 구현 및 시험: 테넌트 격리 시험을 릴리스 전 보안 시험 항목과 연계해요.
- 14.2.1 물리적 위치 및 영역분리, 14.3.5 영역분리: 공공기관 이용 시 국내 리전 위치와 영역 분리 요건을 구성도에 반영해요.

## 5. 양식 작성 규칙

- `{{ }}`로 표시한 자리표시자는 실제 값으로 바꿔요. 표의 빈 칸은 해당 값을 채워요.
- 서명이 필요한 문서는 서명본을 스캔해 보관하고, md 원본에는 서명본 보관 위치를 적어요.
- 문서를 개정하면 문서 정보 표의 버전과 개정 이력을 갱신해요. 기록 문서(03, 04)는 이전 버전을 삭제하지 않고 보관해서 특정 시점의 구성과 검토 이력을 확인할 수 있게 해요.
- 법령 인용은 개인정보의 안전성 확보조치 기준 제6조(접근통제)·제6조의2(인터넷망의 차단 조치 등)(개인정보보호위원회고시 제2026-9호, 2026. 7. 1. 시행) 기준이에요. 고시가 개정되면 국가법령정보센터에서 조문을 다시 확인해요.
- 준수 검토 주기(분기 1회)는 해설서 예시를 따른 당사 기본값이에요. 위험평가 결과에 따라 조정할 수 있지만, 조정하면 01 지침과 04 검토서를 함께 고쳐요.
- VPC, 서브넷, 보안 그룹, 네트워크 ACL, 피어링, NAT 게이트웨이 같은 용어는 예시예요. 이용하는 IaaS/PaaS 제공자의 실제 서비스 명칭으로 바꿔요.
