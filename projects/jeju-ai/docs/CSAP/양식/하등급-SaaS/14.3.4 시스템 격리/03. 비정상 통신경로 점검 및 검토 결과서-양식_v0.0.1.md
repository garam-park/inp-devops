## 3. 격리 통제 점검 결과

해설서 점검항목의 요구사항을 하나씩 확인한다. 미흡 판정은 5항에 조치 계획을 기록한다.

| No | 점검 항목 | 확인 방법·증적(04 점검표 No) | 결과 | 비고 |
| --- | --- | --- | --- | --- |
| 1 | 관리자가 이용 기관에 할당된 자원(메모리·저장공간 등)·데이터에 임의 접근하지 못하도록 접근제어·격리 등 기술적 접근통제 수단이 동작한다 | {{접근통제 설정, 승인 기반 접근 기록 확인}} | {{적정 / 미흡}} | |
| 2 | 이용자가 본인에게 할당된 자원 이외의 자원에 접근하지 못하도록 기술적 통제 수단이 동작한다(테넌트 식별자 검증 포함) | {{타 테넌트 자원 접근 시험 결과}} | {{적정 / 미흡}} | |
| 3 | 원격관리서버(SSH 등) 설정이 지침 6.1항 기준을 준수하고, 정상 통신경로 외 원격 접속 경로가 차단되어 있다 | {{sshd 설정, 보안 그룹 규칙 확인}} | {{적정 / 미흡}} | |
| 4 | 테넌트 네임스페이스 간 네트워크 통신이 기본 차단되어 있다(NetworkPolicy 적용, 전체 네임스페이스 누락 없음) | {{NetworkPolicy 적용 목록, 네임스페이스 간 통신 시험}} | {{적정 / 미흡}} | |
| 5 | 이용자별 컨테이너가 혼용 운영되지 않고 상호 통신이 차단되어 있다 | {{워크로드 배치 현황, 통신 시험}} | {{적정 / 미흡}} | |
| 6 | 클라우드 시스템이 무선망과 분리되어 있고 무선접속이 통제된다 | {{네트워크 구성, 차단 규칙 확인}} | {{적정 / 미흡}} | |
| 7 | 가상머신 탈출, 은닉 채널 생성 등 격리 우회 취약점을 점검했고 보안패치가 적용되어 있다(제공자 책임 영역은 공지·조치 확인) | {{취약점 점검 결과, 패치 이력}} | {{적정 / 미흡}} | |

| 9 | 접속기록을 자동화된 방식으로 분석하여 불법적인 개인정보 유출, 오용·남용 시도를 탐지하고 사유를 소명하게 하는 기능이 동작한다 | {{자동 분석 설정, 탐지·소명 기록}} | {{적정 / 미흡}} | |
