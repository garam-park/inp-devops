해설서 증거자료 중 기술 증적(추가 인증수단 적용 화면 등)을 무엇을 보고 수집할지 정하고, 수집 이력을 관리하는 점검표다. 03. 인증 수단 적용 현황표의 증적 열과 04. 강화된 인증 수단 요청 처리 대장의 적용 확인 열은 본 점검표의 No를 참조한다.

## 1. 수집 원칙

- 화면 캡처에는 시스템명·URL(또는 메뉴 경로), 캡처 일시, 로그인 계정(운영자 식별 가능 수준)이 함께 보이게 한다. 브라우저 주소창과 시스템 시계를 포함해 캡처한다.
- 개인정보(이용자 성명·이메일·휴대폰 번호 등)와 비밀 값(OTP 시드, 인증코드, API 키)은 마스킹하되, 확인 항목의 판단에 필요한 부분은 가리지 않는다.
- 로그인 흐름 증적은 1차 인증 화면과 2차 인증 화면을 연속으로 캡처하여 2차 인증을 생략할 수 없음이 드러나게 한다.
- 증적은 {{증적 보관 위치: 문서관리시스템 경로 등}}에 "10.3.3/{{No}}-{{수집일}}" 규칙으로 저장하고, 수집일이 6개월을 지나면 다시 수집한다(03. 현황표 6항과 동일 기준).
- 수집 결과 확인 항목을 충족하지 못하는 증적(2차 인증 없이 로그인되는 화면 등)이 나오면 즉시 정보보호 관리자에게 보고하고 3항에 조치를 기록한다.
