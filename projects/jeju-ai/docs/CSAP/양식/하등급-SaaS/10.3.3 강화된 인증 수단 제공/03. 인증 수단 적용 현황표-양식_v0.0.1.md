## 6. 현행화 규칙

- 신규 접점 배포, 인증 수단 추가·변경, 예외 승인·해소, 이용 기관 요청 적용 시 {{n}}영업일 이내에 갱신하고 버전을 올린다.
- 반기 1회 이상 5항의 자료와 전면 대조하고, 결과를 반영한 버전을 정보보호 최고책임자가 승인한다.
- 모든 버전을 {{3}}년 이상 보관하여 특정 시점의 적용 현황을 확인할 수 있게 한다.
- 2항의 증적 열은 05. 증적 수집 점검표의 No와 맞추고, 증적 수집일이 기준일보다 {{6}}개월 이상 오래되면 다시 수집한다.
