# 14.3.3 데이터 유출 방지 산출물 목록

## 2. 권장 작성 순서

1. 01 공공 데이터 국외 유출 방지 지침: 국내 위치 제한·국외 유출 차단 원칙과 기술적 보호조치, 검토·증적 제공 기준을 정하고 정보보호 최고책임자 승인을 받아요.
2. 05 증적 수집 점검표: 리전 설정, 국외 생성·복제 차단 정책, 접근 권한 목록, 위치 조회 화면 등 현재 설정 증적을 수집해서 상태를 확인해요.
3. 02 공공 데이터 저장 위치 관리대장: 수집한 증적을 근거로 데이터 유형별 저장 위치와 외부 연동의 데이터 위치를 목록으로 작성해요.
4. 04 물리적 위치 증적 제공 관리대장: 이용 기관에 제공할 표준 증적 꾸러미와 제공 절차를 정하고 최신 상태로 준비해요.
5. 03 데이터 물리적 위치 검토서: 반기마다 실제 자원·설정과 대장을 전면 대조하고 결과를 02 대장에 반영해요.

## 3. 심사 대비 체크리스트

- [ ] 공공 데이터의 국외 유출 방지를 위한 정책·지침을 수립하고 승인받았다.
- [ ] 공공 서비스의 모든 데이터·백업·가상자원이 국내 리전에만 위치하고, 국외 리전에 가상자원을 생성할 수 없도록 기술적 차단 정책이 적용되어 있다.
- [ ] 데이터·백업의 국외 복제·복사 설정이 없고, 외부 연동 서비스(CDN, 모니터링, 오류 수집, 메일 발송 등)로 공공 데이터가 국외에 저장·전송되지 않음을 점검했다.
- [ ] 서비스의 데이터 저장 위치가 국내로 고정되어 있음을 이용 계약·서비스 안내에 명시했다.
- [ ] 공공 가상자원·데이터에는 공공 주요 직무자 외(민간 서비스 인력 등)가 접근·제어할 수 없고, 권한 목록을 2.1.2 주요 직무자 목록과 대조했다.
- [ ] 자원의 물리적 위치를 확인·추적하는 기술적 방안(리전별 리소스 조회, 감사 로그, 위치 태그)이 동작하고 증적을 보관하고 있다.
- [ ] 반기 1회 이상 실제 자원·설정과 대조한 물리적 위치 검토 기록이 있다.
- [ ] 이용 기관이 물리적 위치 증적을 요청하면 기한 내 제공하는 절차와 표준 증적이 준비되어 있고, 제공 이력을 기록·보관한다.
- [ ] 자원·설정·외부 연동 변경 시 저장 위치 관리대장을 현행화하는 규칙이 있다.

## 4. 관련 산출물(다른 항목)

- 10.1.2 접근기록 관리: 감사 로그·접근기록의 수집·보관·검토 체계를 위치 추적과 국외 접근 확인에 활용해요.
- 14.1.1 보안서비스 수준 협약: 제공자 계약·SLA에서 인프라의 국내 위치 보장과 위치 증명 협조 조건을 확인해요.
- 14.2.1 물리적 위치 및 영역분리: 자산 위치 및 영역 목록·국외 접속 차단 설정과 02 대장·05 점검표를 일치시켜요. 제공자 CSAP 인증서 증적은 공용할 수 있어요.
- 14.2.2 중요장비 이중화 및 백업체계 구축: 백업 시스템·백업 데이터의 위치가 02 대장과 일치해야 해요.

## 5. 양식 작성 규칙

- `{{ }}`로 표시한 자리표시자는 실제 값으로 바꿔요. 표의 빈 칸은 해당 값을 채워요.
- 서명이 필요한 문서는 서명본을 스캔해 보관하고, md 원본에는 서명본 보관 위치를 적어요.
- 문서를 개정하면 문서 정보 표의 버전과 개정 이력을 갱신해요. 관리대장(02, 04)은 이전 버전을 보관해서 특정 시점의 현황을 확인할 수 있게 해요.
- 화면 캡처 증적에는 촬영 일시와 계정·시스템 식별 정보가 보이게 하고, 05 점검표의 보관 위치에 모아 관리해요.
- 법령 인용은 「행정기관 및 공공기관의 클라우드컴퓨팅서비스 이용 기준 및 안전성 확보 등에 관한 고시」 제13조(행정안전부고시 제2025-79호, 2025. 12. 29. 시행) 기준이에요. 관련 근거인 국가 사이버보안 기본지침 제24조의3(클라우드컴퓨팅 도입 가능 목록)은 비공개 지침이라 문서명만 표기해요. 법령·고시가 개정되면 국가법령정보센터에서 조문을 다시 확인해요.
