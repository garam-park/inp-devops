## 1. 사용 방법

- 14.3.3 심사에서 확인하는 기술 증적(데이터 유출 방지 기능의 설정 화면, 물리적 위치 추적·검토 화면·기록)을 한곳에서 관리한다. 양식 02. 관리대장과 양식 03. 검토서의 내용이 실제 설정과 일치함을 뒷받침하고, 양식 04. 증적 제공 관리대장의 표준 증적 원천이 된다.
- 화면 캡처에는 촬영 일시, 계정·시스템 식별 정보가 보이게 하고, 파일명은 `14.3.3_증적No_YYYYMMDD` 형식으로 저장한다.
- 수집 주기가 도래하면 수집일을 갱신하고 이전 증적도 보관하여 이력을 유지한다.
