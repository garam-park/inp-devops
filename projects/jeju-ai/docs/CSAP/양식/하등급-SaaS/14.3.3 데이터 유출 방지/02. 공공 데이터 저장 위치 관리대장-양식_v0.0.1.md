## 1. 사용 방법

- {{서비스명}}의 공공 데이터등(데이터, 백업, 로그, 임시 저장 포함)이 어디에 저장·전송되는지 한곳에서 관리하고, 물리적 위치를 확인·추적하는 기초 자료로 사용한다.
- 각 행의 위치 확인 방법에는 심사원·이용 기관 앞에서 실제 위치를 재현해 보일 수 있는 조회 수단(콘솔 메뉴, CLI·API 명령, 태그)을 적는다.
- 자원·설정·연동이 바뀌면 {{n}}영업일 이내에 갱신하고, 반기 검토(양식 03. 데이터 물리적 위치 검토서) 결과를 반영해 버전을 올린다. 이전 버전은 보관하여 특정 시점의 위치 현황을 확인할 수 있게 한다.
- 자산의 전체 목록과 영역 배치는 14.2.1 자산 위치 및 영역 목록과 일치해야 한다. 본 대장은 그중 데이터의 저장·전송 위치를 상세화한다.
