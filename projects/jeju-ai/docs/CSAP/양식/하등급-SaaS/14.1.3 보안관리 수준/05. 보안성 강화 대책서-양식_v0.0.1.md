> [!info] 법령 기준
> 세부 보안 요구사항은 「국가 사이버보안 기본지침」 제24조의4와 「클라우드 컴퓨팅 보안 가이드라인」(국가정보원)을 준수한다. 두 문서는 비공개·수시 개정 문서이므로 문서명 기준으로 인용하며, 국가기관등 이용 기관이 최신 요구사항을 제시하면 그에 따라 본 대책을 갱신한다.

## 1. 목적

{{회사명}}은(는) 클라우드컴퓨팅서비스 {{서비스명}}(하등급 SaaS)이 국가기관등의 보안수준을 만족할 수 있도록 해설서 점검항목 해설의 보안성 강화 방안을 본 문서로 수립하고 운영·점검한다.

## 2. 적용 범위

- {{서비스명}} 인증 범위 내 응용 프로그램, 데이터(백업 포함), 서버, 네트워크 설정
- 국가기관등에 제공하는 서비스에서 처리되는 기관의 중요 데이터 전체

## 3. 대책별 현황

### 3.1 데이터 처리 과정의 데이터 보호 방안

애플리케이션의 데이터 처리(송·수신, 저장, 연산 등) 과정에서 데이터를 보호한다.

| 처리 과정 | 보호 대책 | 적용 대상·설정 | 확인 방법 |
| --- | --- | --- | --- |
| 송·수신 | TLS {{1.2}} 이상 암호화 통신 채널 적용 | {{서비스 웹·API 전 구간, 관리자 접속}} | {{TLS 설정 화면, 인증서}} |
| 저장 | 저장 데이터 암호화(검증필 암호모듈 기준은 14.3.1 산출물을 따름) | {{DB 암호화 대상 컬럼, 스토리지·백업 암호화 설정}} | {{암호화 설정 화면}} |
| 연산·처리 | 처리 중 데이터 접근통제(권한 차등, 세션 관리), 처리 후 임시 데이터 삭제 | {{응용 권한 체계, 임시 파일 정리 배치}} | {{권한 설정, 처리 로그}} |
| 출력·다운로드 | 다운로드·출력 권한 제한과 사유 기록 | {{관리자 기능 다운로드 통제}} | {{권한 설정, 다운로드 로그}} |

### 3.2 데이터 무결성 확인 방안

기관의 중요 데이터에 대한 입·출력, 전송 또는 교환 및 저장 과정에서 데이터가 변조되지 않았음을 확인한다.

| 과정 | 무결성 확인 대책 | 적용 대상·설정 | 확인 방법 |
| --- | --- | --- | --- |
| 입·출력 | 입력값 검증, 처리 결과 검증({{체크섬·건수 대사}}) | {{파일 업로드·다운로드, 일괄 처리}} | {{검증 로직, 처리 로그}} |
| 전송·교환 | TLS 무결성 보장(MAC), API 요청 {{서명·해시}} 검증 | {{외부 연계 API}} | {{TLS 설정, 연계 규격서}} |
| 저장 | DB 무결성 제약, 변경 이력 기록, 파일 해시 관리 | {{주요 테이블, 저장 파일}} | {{스키마, 변경 로그}} |
| 백업 | 백업 무결성 검증({{체크섬 비교, 복구 시험}}) | {{백업 데이터}} | {{백업 검증 기록(14.2.2 산출물과 연계)}} |
