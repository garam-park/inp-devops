## 1. 목적과 책임 범위

- 국가기관용 클라우드컴퓨팅서비스에 관련된 물리적 시설(시스템이 설치된 데이터센터, 운영 인력이 근무하는 당사 시설)의 국내 위치와 출입통제 현황을 확인한다.
- 당사는 CSAP 인증을 받은 IaaS/PaaS 인프라를 이용하는 SaaS 제공자로서 데이터센터를 직접 운영하지 않는다. 책임공유모델에 따라 데이터센터의 물리 보안·출입통제는 제공자 책임이며 제공자 인증·계약으로 확인하고, 당사는 운영 측면(당사 운영 시설의 위치·출입통제, 운영 인력의 국내 근무)을 관리한다.

## 2. 시설 전체 구성

```mermaid
flowchart LR
    subgraph KOREA["대한민국(국내)"]
        subgraph DC["제공자 데이터센터({{소재지 시·도}})"]
            IAAS["IaaS/PaaS 인프라<br/>공공기관용 영역<br/>(물리 보안: 제공자 책임)"]
        end
        subgraph OFFICE["당사 사무실({{소재지 시·도}})"]
            OPS["운영 공간(운영 인력 근무)"]
            SEC["출입통제(카드키·출입기록)"]
        end
        REMOTE["국내 원격 근무지<br/>(VPN, 국외 IP 차단)"]
    end

    OPS -->|VPN + 다중 인증| IAAS
    REMOTE -->|VPN + 다중 인증| IAAS
    SEC -.출입통제.- OPS
```

- 시설이 여럿이면 노드를 추가하고, 실제 소재지에 맞게 수정한다. 국외 시설은 존재하지 않아야 한다.
