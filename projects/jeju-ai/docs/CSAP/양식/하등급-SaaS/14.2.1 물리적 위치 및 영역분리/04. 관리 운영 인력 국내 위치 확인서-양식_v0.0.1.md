## 1. 목적과 대상

- {{서비스명}}의 운영·관리 업무(사고 및 장애 대응, 이용자 계정 권한 부여·변경·삭제, 시스템·데이터 운영, 배포, 모니터링 등)를 수행하는 인력이 국내에 거주하며 국내에서 업무를 수행함을 확인한다. 국외에서 원격으로 클라우드서비스를 운영·관리하는 경우는 부적합이므로 이를 예방·점검한다.
- 대상: 임직원과 외부인력(파견·용역·위탁)을 포함해 운영·관리 권한을 보유한 전원. 주요 직무자 목록(2.1.2)의 운영·관리 직무자와 대조하여 누락이 없게 한다.

## 3. 국외 접속 통제 확인

인력 확인과 별개로, 시스템 측면에서 국외로부터의 운영·관리 접속이 차단되어 있는지 확인한다.

| 1 | 클라우드 콘솔 접근이 국내 허용 IP(VPN)로 제한되어 있다 | {{콘솔 접근 정책 화면}} | {{적합 / 부적합}} | |
| 2 | 서버 원격 접속(SSH 등)이 배스천·허용 IP로 제한되어 있다 | {{보안 그룹 규칙}} | | |
| 3 | 서비스 관리자 기능 접근이 허용 IP로 제한되어 있다 | {{관리자 페이지 접근 설정}} | | |
| 4 | VPN 접속이 국내에서만 가능하도록 설정되어 있다(국외 IP 차단) | {{VPN 정책 화면}} | | |
| 5 | 점검 기간의 관리자 접속 기록에 국외 IP 접속이 없다 | {{접속 기록 조회({{기간}})}} | {{국외 접속 0건 / 발견 n건}} | |

## 4. 국외 체류 발생 시 절차

1. 운영·관리 인력이 국외 출장·연수·이주 등으로 국외에 체류하게 되면 사전에 부서장과 정보보호 관리자에게 보고한다.
2. 국외 체류 기간에는 운영·관리 업무를 수행하지 않으며, 필요하면 체류 전에 운영·관리 권한을 일시 회수하거나 계정을 비활성화한다.
3. 해당 업무는 국내의 대체 인력이 수행하도록 지정한다: 대체 지정 기록 {{ }}
4. 국외 이주 등으로 국내 거주 요건을 상실하면 운영·관리 직무에서 해제하고 권한을 회수하며, 주요 직무자 목록(2.1.2)에도 반영한다.
