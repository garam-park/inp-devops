# 14.2.1 물리적 위치 및 영역분리 산출물 목록

하등급 SaaS 인증 기준 14.2.1(클라우드 시스템·백업 시스템·데이터와 관리·운영 인력의 물리적 위치 국내 한정, 국가기관용 서비스 영역과 일반 이용자용 영역의 물리적 또는 논리적 분리)을 충족하기 위해 준비할 산출물과 각 양식의 용도를 정리한 문서예요. 당사는 CSAP 인증을 받은 IaaS/PaaS 인프라를 이용하는 SaaS 제공자라서 데이터센터 물리 보안은 제공자 인증·계약으로 확인하고, 운영 측면(자산 배치 위치, 영역분리 설정, 운영 인력·시설의 국내 위치)을 산출물로 증명해요.

## 2. 권장 작성 순서

1. 05 증적 수집 점검표: 제공자 CSAP 인증서와 콘솔 설정 화면(리전, 저장 위치, 영역분리, 국외 접속 차단)을 먼저 수집해서 현재 상태를 확인해요.
2. 01 자산 위치 및 영역 목록: 수집한 증적을 근거로 시스템·데이터·백업 자산의 위치와 배치 영역을 목록으로 작성하고, 외부 연동 서비스의 데이터 위치까지 점검해요.
3. 02 네트워크 구성도: 실제 계정·VPC·보안 그룹 설정과 일치하게 영역분리와 접근 경로를 그려요.
4. 03 시설구성도: 데이터센터(제공자 확인)와 당사 운영 시설의 위치·출입통제를 정리해요.
5. 04 관리 운영 인력 국내 위치 확인서: 운영·관리 권한 보유자 전원의 국내 거주와 접속 기록을 확인하고 승인받아요.

## 3. 심사 대비 체크리스트

- [ ] 국가기관용 서비스의 모든 시스템·데이터·백업이 국내 리전(대한민국의 배타적 법적관할하 시설)에 위치하고, 확인 근거(설정 화면·인증서)를 보관하고 있다.
- [ ] 이용하는 IaaS/PaaS가 CSAP 인증을 받았고, 인증 범위에 공공기관용 영역과 이용 리전이 포함되어 있으며, 인증서 사본과 확인일을 기록했다.
- [ ] 이용자 데이터가 인증받지 않은 영역(국외, 민간 등)에 저장되지 않으며, 교차 리전 복제나 외부 연동 서비스(CDN, 모니터링, 오류 수집, 메일 발송 등)를 통한 국외 저장이 없음을 점검했다.
- [ ] 민간용 서비스를 함께 제공하는 경우 국가기관용 영역과 민간용 영역이 물리적 또는 논리적(계정·VPC·보안 그룹 분리)으로 분리되어 있고, 구성도가 실제 설정과 일치한다.
- [ ] 운영·관리 인력(사고·장애 대응, 계정 권한 부여·변경·삭제 등) 전원이 국내에 거주하며, 국외에서 원격으로 운영·관리하지 않는다.
- [ ] 클라우드 콘솔·서버·관리자 기능 접근이 국내 허용 IP(VPN)로 제한되고 국외 IP가 차단되어 있으며, 접속 기록으로 국외 접속이 없음을 확인했다.
- [ ] 당사 운영 시설에 물리적 출입통제를 수행하고 출입기록을 유지한다.
- [ ] 운영 인력의 국외 출장·이주 시 권한을 통제하는 절차가 있고 이행 기록이 있다.
- [ ] 자산·네트워크·시설·인력 변경 시 목록과 구성도를 현행화하는 규칙이 있고, 반기 1회 이상 실제 설정과 대조한 기록이 있다.

## 4. 관련 산출물(다른 항목)

- 2.1.2 주요 직무자 지정 및 감독: 운영·관리 권한 보유자를 주요 직무자 목록으로 관리하고, 04 확인서의 대상 인력과 대조해요.
- 10.1.2 접근기록 관리: 관리자 접속 기록(접속 IP 포함)의 수집·보관·검토 체계를 활용해서 국외 접속 없음을 확인해요.
- 11.1.5 네트워크 분리: 네트워크 분리 구성·설정의 상세 산출물과 02 네트워크 구성도를 일치시켜요.
- 14.1.1 보안서비스 수준 협약: 제공자 계약·SLA에서 인프라의 국내 위치와 공공기관용 영역 제공 조건을 확인해요.
- 14.2.2 중요장비 이중화 및 백업체계 구축: 백업 시스템·백업 데이터의 구성이 01 목록의 위치 확인과 일치해야 해요.
- 14.3.3 데이터 유출 방지: 공공 데이터의 유출 방지 통제와 01 목록의 외부 연동 점검을 연계해요.
- 14.3.4 시스템 격리: 비정상 통신경로 점검 결과로 영역 간 간섭·우회 경로가 없음을 보완 확인해요.
- 14.3.5 영역분리: 영역분리의 기술적 보호조치(취약점 방지, 비인가 접근 모니터링) 상세 산출물과 02 구성도를 연계해요.

## 5. 양식 작성 규칙

- `{{ }}`로 표시한 자리표시자는 실제 값으로 바꿔요. 표의 빈 칸은 해당 값을 채워요.
- 서명이 필요한 문서는 서명본을 스캔해 보관하고, md 원본에는 서명본 보관 위치를 적어요.
- 문서를 개정하면 문서 정보 표의 버전과 개정 이력을 갱신해요. 목록·확인서(01, 04)는 이전 버전·회차를 보관해서 특정 시점의 현황을 확인할 수 있게 해요.
- 화면 캡처 증적에는 촬영 일시와 계정·시스템 식별 정보가 보이게 하고, 05 점검표의 보관 위치에 모아 관리해요.
- 이 항목의 관련 근거인 국가 사이버보안 기본지침 제24조의3(클라우드컴퓨팅 도입 가능 목록)은 공개 조문을 확인할 수 없어서 문서명만 표기해요. 이 항목 양식은 별도 법령 조문을 인용하지 않으며, 법령·지침이 개정되면 국가법령정보센터와 관계 기관 공지에서 다시 확인해요.
