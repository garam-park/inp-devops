# 보안관제 제반환경 지원 절차

> [!info] 법령 기준
> 사이버안보 업무규정 제14조(대통령령 제34287호, 2024. 3. 5. 시행)를 기준으로 작성했다. 제14조제2항에 따라 국가기관등은 통합보안관제체계와 연계된 보안관제센터를 설치·운영하거나 다른 기관의 보안관제센터를 활용하며, 제14조제4항에 따라 국가정보원장은 클라우드컴퓨팅서비스 제공자에게 보안관제에 필요한 협조 또는 지원을 요청할 수 있다. 국가 사이버보안 기본지침 제24조의3·제24조의4·제131조와 국가 클라우드 컴퓨팅 보안 가이드라인(부록7 민간 클라우드 컴퓨팅 서비스 보안관제 체계 포함)은 비공개 문서라 문서명만 적는다. 법령이 개정되면 국가법령정보센터에서 조문을 다시 확인한다.

## 1. 목적

{{회사명}}은(는) 클라우드컴퓨팅서비스 {{서비스명}}(하등급 SaaS)을 국가기관등에 제공할 때, 이용기관이 공공 영역 대상 사이버공격·위협을 탐지하기 위한 보안관제를 수행하고 그 탐지정보를 정부보안관제체계와 연계할 수 있도록 필요한 제반환경을 지원하는 기준과 절차를 정한다.

## 2. 적용 범위

- {{서비스명}}을 이용하는 모든 국가기관등(중앙행정기관, 지방자치단체, 공공기관)과의 계약
- 이용기관의 보안관제센터(자체 운영 또는 다른 국가·공공기관 보안관제센터 위탁)와 정부보안관제체계에 대한 연계 지원 업무
- 보안관제 지원을 위해 당사가 제공하는 로그, 보안이벤트, 탐지정보, 계정, 연계 구간 전체

## 3. 용어 정의

| 용어 | 정의 |
| --- | --- |
| 보안관제 | 사이버공격·위협을 즉시 탐지·대응하는 활동(사이버안보 업무규정 제14조제1항) |
| 정부보안관제체계 | 국가정보원장이 구축·운영하는 통합보안관제체계와 이에 연계된 국가·공공기관 보안관제 체계 |
| 이용기관 보안관제 영역 | 이용기관이 보안관제를 수행하는 영역. 자체 보안관제센터 또는 위탁받은 다른 기관의 보안관제센터를 포함한다. |
| 탐지정보 | 이용기관 보안관제 영역에서 탐지기술을 적용해 생성하거나, 당사가 서비스 운영 중 탐지하여 제공하는 사이버공격·위협 관련 정보 |
| 제반환경 | 이용기관의 보안관제 수행과 정부보안관제체계 연계에 필요한 로그·이벤트 제공 체계, 관제용 접근 수단, 연계 구간, 협조 체계 등 일체 |

## 4. 책임공유모델에 따른 지원 범위

당사는 IaaS/PaaS 제공자의 인프라 위에서 SaaS를 제공하므로, 보안관제 제반환경 지원 책임을 다음과 같이 구분한다.

| 주체 | 책임 범위 |
| --- | --- |
| 당사(SaaS 제공자) | 서비스·응용 계층의 로그와 보안이벤트 생성·제공, 보안관제용 접근 수단 제공, 이용기관 보안관제 영역·정부보안관제체계와의 연계 기반 제공, 침해사고 관련 협조 |
| IaaS/PaaS 제공자 | 물리 인프라·하이퍼바이저·네트워크 기반 계층의 보안관제 기반. CSAP 인증({{인증번호}})과 이용 계약으로 확인하고, 당사가 활용 가능한 관제 지원 기능(플로우 로그, 트래픽 미러링 등)의 범위를 5항에 반영한다. |
| 이용기관 | 보안관제 수행 주체 결정(자체 또는 위탁), 보안관제 영역에서 탐지기술 적용·보안관제 수행, 탐지정보의 정부보안관제체계 연계 |

- {{서비스명}}이 이용기관 전용 격리 영역(전용 VPC 등)을 제공하는 구조이면 해당 영역에서 이용기관이 보안관제를 수행할 수 있는 기반(로그·트래픽 정보 접근 등)을 5항 항목으로 정의해 제공한다. 해당 없음: {{해당 / 해당 없음}}

## 5. 제공 가능한 제반환경 항목

당사가 국가기관등에 제공할 수 있는 제반환경 항목을 다음과 같이 정의한다. 기관별 제공 여부와 구성 내용은 양식 02. 보안관제 연계 환경 구성 내역서에 기록한다.

| 항목 코드 | 항목 | 내용 | 제공 방식 | 비고 |
| --- | --- | --- | --- | --- |
| ENV-01 | 서비스 로그 제공 | 응용 로그, 이용자·관리자 접근기록, 인증 성공·실패 기록, 관리자 행위 기록 | {{API / 파일 전송 / syslog 전송}} | 10.1.2 접근기록 관리와 연계 |
| ENV-02 | 보안이벤트·탐지정보 제공 | 당사 보안 시스템({{WAF, 접근제어 등}})의 탐지 이벤트와 침해 시도 정보의 실시간 또는 주기 전송 | {{syslog / API / 웹훅}} | |
| ENV-03 | 보안관제용 접근 수단 | 이용기관 또는 위탁 관제센터의 관제 요원에게 제공하는 조회 전용 계정·대시보드 | {{관제용 계정 / 대시보드 URL}} | 조회 전용 권한, 다중 인증 적용 |
| ENV-04 | 정부보안관제체계 연계 기반 | 이용기관 보안관제 영역이 탐지정보를 정부보안관제체계와 연계할 수 있도록 요구 형식·전송 방식에 맞춘 로그·탐지정보 제공 | {{기관 요구 형식에 따름}} | 부적합 사례 1 예방 |
| ENV-05 | 연계 구간 구성 | 당사 서비스와 이용기관 보안관제 영역 간 전송 구간의 구성과 전송 구간 암호화 | {{TLS / VPN}} | 전송 구간 암호화는 국가정보원 검증필 암호모듈 적용(14.3.1 연계) |
| ENV-06 | 연계 시험 지원 | 연계 구성·변경 시 로그 수신, 탐지정보 연계, 암호화 적용을 확인하는 시험 지원 | 시험 계획·결과 상호 확인 | |
| ENV-07 | 침해사고 협조 | 침해사고·이상징후 관련 정보 공유, 국가정보원·보안관제센터의 협조 또는 지원 요청 대응 | 협조 창구: {{정보보호 관리자}} | 사이버안보 업무규정 제14조제4항, 14.1.4 연계 |

- 이용기관이 위 항목 외의 환경을 요구하면 지원 가능성을 검토해 항목을 추가하고, 본 절차를 개정한다.

## 6. 지원 절차

| 단계 | 담당 | 내용 | 기록 |
| --- | --- | --- | --- |
| 1. 계약 전 사전 검토 | 영업 담당, 정보보호 관리자 | 기관의 보안관제 주체·요구 연계 방식을 확인하고 7항 체크리스트로 지원 가능 여부를 검토. 지원 불가 항목이 있으면 계약 전에 대안을 협의 | 7항 사전 검토 체크리스트 |
| 2. 요구사항 접수 | 운영 담당 | 계약·협약(14.1.1)과 기관 협의로 보안관제 지원 요구사항 접수 | 양식 02 2항 |
| 3. 협의·확정 | 정보보호 관리자 | 요구사항별 지원 방법·일정 협의, 5항 항목 코드로 확정 | 양식 02 2항 |
| 4. 구성·연계 | 시스템 담당자 | 로그·이벤트 전송, 관제용 계정, 연계 구간 구성. 전송 구간 암호화 적용 | 양식 02 3항 |
| 5. 연계 시험 | 시스템 담당자, 기관 담당자 | 로그 수신·탐지정보 연계·암호화 적용을 기관과 상호 확인 | 양식 02 5항 |
| 6. 운영·모니터링 | 운영 담당 | 연계 상태 상시 모니터링, 전송 중단·장애 시 {{n}}시간 이내 기관 통보·복구 | 연계 상태 점검 기록, 양식 04 |
| 7. 정기 보고 | 정보보호 관리자 | 월간 단위로 제반환경 제공 상태·보안이벤트 현황을 기관에 보고 | 양식 03. 보안관제 월간보고자료 |
| 8. 변경 관리 | 정보보호 관리자 | 서비스·연계 구성 변경 시 기관에 사전 통보하고 재시험 후 구성 내역서 갱신 | 양식 02 6항 |

## 7. 계약 전 사전 검토 체크리스트

부적합 사례(정부보안관제체계 연계 제반환경 마련 불가, 기관 요구 연계 지원 불가)를 예방하기 위해 계약 체결 전에 확인한다.

| No | 확인 항목 | 결과 | 확인자 |
| --- | --- | --- | --- |
| 1 | 기관의 보안관제 주체(자체 보안관제센터 / 다른 기관 보안관제센터 위탁)를 확인했다 | {{○ / X}} | |
| 2 | 기관이 요구하는 로그·탐지정보의 종류와 형식을 당사가 제공할 수 있다 | {{○ / X}} | |
| 3 | 기관이 요구하는 전송 방식(API, syslog 등)과 연계 구간 구성을 당사가 지원할 수 있다 | {{○ / X}} | |
| 4 | 탐지정보의 정부보안관제체계 연계에 필요한 제반환경(형식·전송·암호화)을 지원할 수 있다 | {{○ / X}} | |
| 5 | 전송 구간 암호화에 국가정보원 검증필 암호모듈이 탑재된 제품 또는 검증필 암호화 기능을 적용할 수 있다 | {{○ / X}} | |
| 6 | IaaS/PaaS 제공자의 관제 지원 기능 중 활용이 필요한 기능의 제공 여부를 확인했다 | {{○ / X / 해당 없음}} | |
| 7 | 지원 불가로 판정된 요구가 있으면 대안을 기관과 협의해 합의했다 | {{○ / 해당 없음}} | |

- 지원 불가 항목이 남은 상태로 계약하지 않는다. 불가 항목은 개발·구성 계획과 완료 예정일을 정해 양식 02 2항에 기록하고 이행을 관리한다.
