## 3. 인증·암호화 영향 검토

정보보호 관리자가 확인한다. 하나라도 "예"이면 4항의 반영·시험 확인을 수행한 뒤 배포하고, 모두 "아니오"이면 영향 없음으로 판정하고 5항으로 넘어간다.

| No | 검토 항목 | 예/아니오 | 관련 요구사항 ID |
| --- | --- | --- | --- |
| 1 | 로그인·인증 수단, 인증 시점, 추가 인증에 변경이 있는가 | | AUTH-01~04 |
| 2 | 패스워드 규칙, 실패 잠금, 오류 메시지 처리에 변경이 있는가 | | AUTH-05~09 |
| 3 | 세션 관리, 동시 접근 제한, 접근 IP 제한에 변경이 있는가 | | AUTH-10~12 |
| 4 | 접근 권한 정책, 사용·관리 권한 부여 방식에 변경이 있는가 | | AUTH-13 |
| 5 | API 연동 추가·변경 또는 인증키 발급·저장 방식 변경이 있는가 | | AUTH-14·15 |
| 6 | 새로 저장·처리하는 중요정보(개인정보, 인증정보 등)가 생기는가 | | ENC-S-01~05 |
| 7 | 중요정보가 이동하는 전송 구간이 신설·변경되는가(프로토콜·버전 변경 포함) | | ENC-T-01~05 |
| 8 | 사용자 입력값을 처리하는 화면·쿼리·기능이 추가·변경되는가 | | SEC-C-01~04 |
