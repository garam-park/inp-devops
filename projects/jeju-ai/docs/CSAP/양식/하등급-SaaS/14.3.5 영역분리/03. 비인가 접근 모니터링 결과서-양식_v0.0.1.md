## 1. 모니터링 체계

양식 01. 영역분리 보호조치 기준 7항에 따라 공공기관용 영역에 대한 비인가 접근과 영역분리 훼손 시도를 모니터링한다. 실시간 알림과 별개로 월 1회 이상 결과를 검토하여 본 결과서를 작성한다(당사 내부 기준).

| No | 모니터링 대상 | 탐지 수단 | 알림 방식 | 동작 확인 |
| --- | --- | --- | --- | --- |
| 1 | 민간용 영역·외부에서 공공기관용 영역으로의 통신·접근 시도 | {{VPC 흐름 로그, 보안 그룹 거부 로그}} | {{실시간 알림 / 일간 집계}} | {{정상 / 이상}} |
| 2 | 공공기관용 영역 자원에 대한 비인가 콘솔·IAM 접근, 권한 변경 | {{클라우드 감사 로그, 로그인 실패·비허용 IP 알림}} | | |
| 3 | 영역 간 피어링·라우팅·터널 등 우회 경로의 생성·변경 | {{감사 로그의 네트워크 구성 변경 이벤트 알림}} | | |
| 4 | VPN·배스천을 거치지 않은 관리 포트 접근 시도 | {{흐름 로그, 배스천 세션 기록 대조}} | | |
| 5 | 응용 계층의 테넌트 간 접근 시도(다른 이용기관 데이터 접근) | {{응용 로그의 인가 실패 이벤트}} | | |

- 탐지 규칙·알림 설정의 화면 증적은 양식 05. 증적 수집 점검표 No 5로 수집한다.
- 로그의 수집·보관 기간은 10.1.2 접근기록 관리 산출물을 따른다.
