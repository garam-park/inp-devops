## 1. 목적

{{회사명}}이(가) 클라우드컴퓨팅서비스 {{서비스명}}에 적용한 정보보호대책이 국가기관등의 보안요구사항(양식 01. 국가기관등 보안요구사항 정의서, 양식 02. 보안서비스 수준 협약서)을 정확하게 반영하고 있는지 지속적으로 모니터링하고, 서비스를 이용하는 국가기관등의 정보보호대책이 의도한 대로 유지·운영되는지 검토하며, 그 결과를 국가기관등에 보고하는 절차를 정한다.

## 2. 적용 범위

- {{서비스명}} 인증 범위 내 정보보호대책 전체와 이를 구성하는 자산·설정·보안정책
- 국가기관등과 체결한 모든 보안서비스 수준 협약(표준계약서·서비스 약관에 보안 사항을 포함한 경우를 포함한다)
- 기반 인프라(IaaS/PaaS) 영역은 제공자의 인증·계약·통지 사항 확인으로 갈음하고, 당사 책임 영역의 설정(보안 그룹, IAM 등)은 직접 모니터링한다.

## 3. 역할과 책임

| 역할 | 책임 |
| --- | --- |
| 정보보호 최고책임자 | 본 절차 승인, 분기 검토 결과와 부적합 조치 계획 승인 |
| 정보보호 관리자 | 모니터링 계획 수립, 결과 취합·검토, 보안영향분석 검토, 보고서(양식 04) 작성 총괄 |
| 정보보호 담당자 | 모니터링 항목별 점검 수행, 기록 작성, 이상 발견 시 보고 |
| 시스템·개발 담당자 | 형상변경 사항 통보, 보안영향분석 수행 협조, 부적합 사항 조치 |

## 8. 부적합·이상 발견 시 조치 절차

1. 발견자는 발견 즉시 정보보호 관리자에게 보고한다.
2. 정보보호 관리자는 영향도(이용기관 데이터·서비스에 대한 영향)를 평가하고, 침해사고에 해당하면 침해사고 대응 절차(5.1.1)를 즉시 개시한다.
3. 조치 계획(담당, 기한)을 수립하여 정보보호 최고책임자의 승인을 받고 조치한다.
4. 이용기관 보안요구사항의 미이행에 해당하면 해당 기관에 통지하고, 조치 결과를 양식 04. 국가기관등 정기 보안 보고서에 반영한다.
5. 조치 완료 후 재발방지 대책을 수립하고 다음 분기 점검에서 이행을 확인한다.

## 9. 결과 보고

- 월간 모니터링 결과는 정보보호 관리자가 취합하여 정보보호 최고책임자에게 보고한다.
- 분기마다 6항 점검표와 7항 수행 기록을 근거로 양식 04. 국가기관등 정기 보안 보고서를 작성하여 협약서 제14조의 주기에 따라 국가기관등에 보고한다.
- 모니터링·점검 기록은 {{3}}년 이상 보관한다.
