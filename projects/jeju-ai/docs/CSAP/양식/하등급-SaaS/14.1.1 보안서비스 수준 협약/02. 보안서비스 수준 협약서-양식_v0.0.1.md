# 보안서비스 수준 협약서

> [!warning] 적용 조건
> 국가기관등과 별도 협약서 대신 표준계약서 또는 서비스 약관에 보안 사항을 포함하는 방식을 택한 경우, 본 양식의 각 조항이 해당 문서의 어느 조항에 반영되었는지를 양식 01. 국가기관등 보안요구사항 정의서 6항 체크리스트로 확인하고 본 협약서 작성은 생략할 수 있다.

> [!info] 법령 기준
> 행정기관 및 공공기관의 클라우드컴퓨팅서비스 이용 기준 및 안전성 확보 등에 관한 고시 제6조(표준계약서 및 서비스 수준 등)·제7조(이용계약 종료 사실의 통지)·제8조(사업 변경 및 종료 사실의 통지)·제14조(저장정보의 반환 및 파기 등)(행정안전부고시 제2025-79호, 2025. 12. 29. 시행)를 기준으로 작성했다. 서비스 수준 항목은 「클라우드컴퓨팅서비스 품질·성능에 관한 기준」과 ISO/IEC 19086(클라우드서비스 수준협약)을 참고한다. 법령·고시가 개정되면 국가법령정보센터에서 조문을 다시 확인한다.

{{회사명}}(이하 "제공자")과(와) {{기관명}}(이하 "이용기관")은 클라우드컴퓨팅서비스 {{서비스명}}의 이용에 관한 보안서비스 수준을 다음과 같이 협약한다.

## 제1조(목적)

이 협약은 제공자가 이용기관에 제공하는 클라우드컴퓨팅서비스의 보안서비스 수준, 양 당사자의 보안 책임, 보안요구사항의 이행·보고에 관한 사항을 정하여 서비스가 이용기관의 보안요구사항을 충족한 상태로 제공되도록 함을 목적으로 한다.

## 제2조(용어의 정의)

| 용어 | 정의 |
| --- | --- |
| 서비스 | 제공자가 이용기관에 제공하는 {{서비스명}}(하등급 SaaS)과 부속 지원 서비스 |
| 이용자 데이터(저장정보) | 이용기관이 서비스에 저장·처리하는 모든 데이터와 그로부터 파생된 데이터 |
| 기반 인프라 제공자 | 제공자가 서비스 운영을 위해 이용하는 IaaS/PaaS 제공자: {{제공자명, CSAP 인증 여부}} |
| 보안서비스 수준 지표 | 제8조에서 정한 보안 관련 서비스 수준 측정 항목 |

## 제3조(서비스 제공 범위)

① 제공자가 제공하는 서비스의 범위는 다음과 같다.

| 구분 | 내용 |
| --- | --- |
| 서비스 기능 | {{제공 기능·모듈}} |
| 서비스 방식 | SaaS({{퍼블릭 / 공공 전용}} 영역), 기반 인프라: {{IaaS/PaaS 제공자명·리전}} |
| 지원 범위 | {{기술 지원 창구, 지원 시간, 장애 접수 방법}} |
| 제외 범위 | {{예: 이용기관 내부망 구성, 이용기관 단말 보안}} |

② 서비스 범위의 변경은 이용기관과 서면으로 합의하여 시행한다.

## 제4조(보안 책임의 구분)

① 양 당사자와 기반 인프라 제공자의 보안 책임은 책임공유모델에 따라 다음과 같이 구분한다.

| 보안 영역 | 기반 인프라 제공자 | 제공자(당사) | 이용기관 |
| --- | --- | --- | --- |
| 물리 보안·데이터센터 | 책임 | 제공자 인증(CSAP 등)·계약으로 확인 | 해당 없음 |
| 네트워크·가상화 인프라 | 책임 | 보안 그룹·방화벽 등 설정 책임 | 해당 없음 |
| 운영체제·미들웨어 | {{PaaS 이용 시 제공자 / IaaS 이용 시 당사}} | 패치·보안 설정 | 해당 없음 |
| 애플리케이션·API | 해당 없음 | 시큐어 코딩, 취약점 점검·조치, 변경 관리 | 해당 없음 |
| 데이터(암호화·백업·파기) | 저장소 암호화·백업 기능 제공 | 암호화 적용, 백업·복구, 완전삭제 | 데이터 분류, 업로드 통제 |
| 계정·접근 관리 | 콘솔 계정 기능 제공 | 관리자 계정·권한 관리, 기관 관리자 계정 발급 | 기관 이용자 계정·권한 관리 |
| 로그·모니터링·사고 대응 | 인프라 로그 제공, 인프라 사고 통지 | 서비스 로그 수집·분석, 사고 대응·통지 | 사고 신고와 협조 |

② 기반 인프라 제공자의 책임 영역은 제공자가 기반 인프라 제공자의 인증 현황과 계약으로 확인하고, 그 결과를 이용기관에 제공한다.

## 제5조(데이터 소유권, 저장 위치 및 보호)

① 이용자 데이터의 소유권은 이용기관에 있으며, 제공자는 서비스 제공 목적 외로 이용자 데이터를 접근·이용·제3자 제공하지 않는다.

② 이용자 데이터(백업 데이터를 포함한다)의 물리적 저장 위치는 대한민국 국내로 한정한다. 저장 위치: {{기반 인프라 제공자명, 국내 리전·데이터센터 소재지}}

③ 제공자는 이용자 데이터를 다음과 같이 보호한다.

| 보호 항목 | 내용 |
| --- | --- |
| 전송 구간 암호화 | {{TLS 1.2 이상 등}}, 검증필 암호모듈 적용: {{모듈명·검증번호}} |
| 저장 데이터 암호화 | {{암호화 대상·방식}} |
| 접근통제 | 이용기관별 데이터 분리({{논리적 분리 방식}}), 접근권한 최소화 |
| 백업 | {{백업 주기·보관 기간·보관 위치(국내)}} |

④ 이용기관이 데이터 이관을 요청하면 제공자는 활용 가능한 형태({{포맷}})로 {{n}}일 이내에 이관을 지원하며, 온라인 이관 시 암호화와 안전한 전송 경로를 적용하고 오프라인 이관 시 암호화한 저장매체를 보호하여 이송한다.

## 제6조(계약 만료·종료 시 데이터 처리)

① 이용계약의 해제·해지 또는 기간 만료로 서비스가 종료되는 경우 제공자는 이용기관의 선택에 따라 다음 각 호 중 어느 하나로 조치한다.

1. 이용자 데이터를 이용기관에 반환한 후 제공자가 보유한 데이터를 복구가 불가능한 방법으로 지체 없이 파기
2. 이용기관이 반환받지 않거나 반환이 불가능한 경우 복구가 불가능한 방법으로 지체 없이 파기
3. 이용자 데이터를 이용기관이 지정한 다른 서비스 제공자에게 이관하고, 제공자가 보유한 데이터를 복구가 불가능한 방법으로 지체 없이 파기

② 파기 범위에는 운영 데이터, 백업 데이터, 로그 내 이용자 데이터, 복제본을 포함한다.

③ 제공자는 파기 완료 후 {{n}}일 이내에 파기 방법·일시·범위를 기재한 파기 확인서(증명 자료 포함)를 이용기관에 제공한다.

## 제7조(제3자·하도급 관계 정보 제공)

① 제공자는 서비스 제공에 관여하여 이용기관에 영향을 미칠 수 있는 제3자·하도급 업체 관계를 이용기관에 제공한다.

| 구분 | 업체명 | 역할 | 이용자 데이터 접근 여부 | 인증·계약상 보안 확인 |
| --- | --- | --- | --- | --- |
| 기반 인프라(IaaS/PaaS) | {{ }} | {{인프라 제공}} | {{X / 접근 범위}} | {{CSAP 인증, 계약서 보안 조항}} |
| {{운영 위탁 / 유지보수 등}} | | | | |

② 제1항의 관계에 변경이 생기면 제공자는 변경 {{n}}일 전까지(긴급한 경우 지체 없이) 이용기관에 통지한다.

## 제8조(보안서비스 수준 지표 및 미달 시 대응·보상)

① 제공자는 다음 보안서비스 수준 지표를 준수한다.

| No | 지표 | 목표 수준 | 측정 방법·주기 | 미달 시 대응 |
| --- | --- | --- | --- | --- |
| 1 | 서비스 가용성 | 월 {{99.9}}% 이상 | {{모니터링 시스템}} 측정, 월별 | 원인 분석·재발방지, 제3항 배상 |
| 2 | 침해사고 통지 | 인지 후 {{n}}시간 이내 이용기관 통지 | 사고 대응 기록, 건별 | 지연 사유 보고, 절차 개선 |
| 3 | 장애 통지·복구 | 통지 {{n}}시간 이내, 복구 목표 {{n}}시간 | 장애 관리 기록, 건별 | 원인 분석·재발방지, 제3항 배상 |
| 4 | 보안패치 적용 | 긴급 취약점 {{n}}일 이내, 일반 {{n}}일 이내 | 패치 관리 기록, 월별 | 미조치 사유·계획 보고 |
| 5 | 취약점 점검·조치 | 점검 {{분기 1회}} 이상, 발견 취약점 {{n}}일 이내 조치 | 점검 결과서, 분기별 | 조치 계획 수립·보고 |
| 6 | 백업 성공률 | {{n}}% 이상 | 백업 결과 기록, 월별 | 실패 원인 분석·재수행 |
| 7 | 보안 보고 이행 | 제14조의 주기 준수 | 보고 이력, 주기별 | 지연 사유 보고 |

② 제공자는 지표 측정 결과를 제14조의 정기 보고에 포함한다.

③ 제공자의 귀책사유로 지표가 목표 수준에 미달한 경우 다음 절차로 대응하고 보상한다.

1. 미달 인지 후 {{n}}일 이내 원인 분석과 재발방지 대책을 이용기관에 보고
2. 이용계약·본 협약에서 정한 기준에 따라 배상: {{예: 월 이용요금 × 배상률표}}

| 가용성(월) | 배상률 |
| --- | --- |
| {{99.0}}% 이상 ~ {{99.9}}% 미만 | 월 이용요금의 {{n}}% |
| {{95.0}}% 이상 ~ {{99.0}}% 미만 | 월 이용요금의 {{n}}% |
| {{95.0}}% 미만 | 월 이용요금의 {{n}}% |

## 제9조(사전인증 제품 및 검증필 암호모듈)

① 제공자는 사전인증이 필요한 제품군(정보보호시스템 등)을 도입하는 경우 국가정보원장이 안전성을 확인한 제품을 도입한다.

② 이용기관 구간 및 서비스 내 주요 정보 전송·저장에 적용하는 암호화에는 국가정보원 검증필 암호모듈을 사용한다. 적용 현황: {{모듈명, 검증번호, 적용 구간}}

## 제10조(사고·장애 대응 및 협조체계)

① 제공자는 사고 또는 장애 발생 시 대내외 관련 기관 및 전문가와 협조체계를 구성하여 대응하고, 발생 사실과 조치 결과를 이용기관에 통지한다.

② 제공자는 국가정보원 및 이용기관의 사고·장애 대응과 예방보안 활동(합동 조사, 자료 제출, 모의훈련 등)에 협조한다.

③ 비상연락체계는 다음과 같으며 변경 시 지체 없이 상호 통지한다.

| 구분 | 소속·직위 | 성명 | 연락처 | 비고 |
| --- | --- | --- | --- | --- |
| 제공자 보안 담당 | | | | 24시간 연락 가능 창구: {{ }} |
| 이용기관 보안 담당 | | | | |

## 제11조(보안관제 및 정부보안관제체계 연계)

① 제공자는 서비스에 대한 클라우드 보안관제를 수행하고, 이용기관이 속한 정부보안관제체계(관계 보안관제센터)와 연계하기 위한 제반환경을 지원한다.

② 제1항의 지원에는 보안관제에 필요한 로그·이벤트의 제공, 연계 인터페이스 협의, 관제 대상 정보의 현행화를 포함한다. 연계 방식: {{예: 보안 이벤트 실시간 전달, 로그 전송 구간·형식}}

## 제12조(현장실사·안전성 보안측정·보안점검 협조)

제공자는 클라우드컴퓨팅서비스 망 운용 관리에 따른 보안 취약점 개선·발굴, 사이버공격 위협 예방·대응, 실태평가, 안전성 및 보안대책의 적합성과 이행 여부 확인 등을 목적으로 국가기관등(국가정보원을 포함한다)이 수행하는 다음 활동에 협조한다.

1. 제공자 시설에 대한 현장실사 방문
2. 안전성 보안 측정 실시
3. 보안진단·점검 등의 수행

## 제13조(기술적 지원 환경 제공)

제공자는 제12조의 현장실사, 안전성 보안측정, 보안점검 등의 수행 목적으로 국가기관등이 기술적 지원을 요청하는 경우 모니터링 도구, 로그 수집 기술 등의 제반환경을 제공한다.

## 제14조(보안요구사항 이행 보고)

① 제공자는 다음 사항을 {{분기}} 1회 이상 이용기관에 보고한다. 보고 양식은 양식 04. 국가기관등 정기 보안 보고서를 따른다.

1. 이용기관 보안요구사항의 구현·이행 현황
2. 보안운영 현황(사고·장애, 취약점 점검·조치, 접근권한 검토, 백업 등)과 모니터링 결과
3. 제8조 보안서비스 수준 지표 측정 결과
4. 자산·구성 변경 사항과 변경 시 보안영향분석 결과

② 침해사고, 중대한 장애, 데이터 유출 등 긴급 사안은 정기 보고와 별도로 제10조에 따라 즉시 통지한다.

## 제15조(계약·사업 종료 사실의 통지)

① 제공자는 이용계약이 종료되는 경우 종료 30일 전까지 이용계약 종료 일시, 저장정보의 처리 방법 및 절차, 담당 부서 및 연락처를 이용기관에 통지한다.

② 제공자는 서비스와 관련된 사업을 변경하거나 종료하는 경우 30일 전까지 변경·종료하려는 사업의 내용 및 사유, 변경·종료 일시, 저장정보의 처리 방법 및 절차, 담당 부서 및 연락처를 이용기관에 통지한다.

③ 통지는 등기우편 또는 내용증명으로 하되, 이용기관과 협의하여 다른 방법·시기로 정할 수 있다: {{협의 결과}}
