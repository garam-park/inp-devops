## 4. 통지 전 확인

| 확인 항목 | 확인 |
| --- | --- |
| 2항의 다섯 항목이 모두 채워졌다(원인 미확인 시 "원인 확인 중" 표기) | {{○}} |
| 통지 방법을 하나 이상 선택했고, 접속화면 게시는 15일 이상으로 설정했다 | |
| 영향받은 모든 이용 기관이 대상에 포함되었고 공공기관은 정보보안담당관을 포함했다 | |
| 통지 근거(법정 중단 기간, 계약 기준, 침해사고, 유출)가 03. 장애 보고서 6항 판정과 일치한다 | |
| 침해사고·정보 유출 동반 시 관계기관 신고가 별도로 진행되고 있다(01. 절차 8.5항) | |
| 정보보호 최고책임자(부재 시 정보보호 관리자) 승인을 받았다 | |
