# 14.3.1 검증필 암호화 기술 제공 산출물 목록

하등급 SaaS 인증 기준 14.3.1(클라우드컴퓨팅서비스를 통해 생성된 중요자료를 암호화하는 수단을 제공하는 경우 검증필 국가표준암호화 기술 제공)을 충족하기 위해 준비할 산출물과 각 양식의 용도를 정리한 문서예요. 심사에서는 VPN, 보안 USB, 호스트 자료유출 방지제품(암호화 저장 기능 보유 시) 등 중요자료 전송·저장에 사용하는 제품의 검증필 암호모듈 탑재 여부와 CC 인증·보안기능 확인서, 두 유효기간의 관리 상태를 확인해요.

## 2. 권장 작성 순서

1. 01 검증필 암호모듈 적용 지침: 필수 제품 유형·도입 요건 기준과 도입·유효기간 관리 절차를 정하고 정보보호 최고책임자 승인을 받아요.
2. 02 정보보호제품 목록: 중요자료 전송·저장에 사용하는 제품을 식별해 검증필 암호모듈 필수 여부, 인증 현황과 함께 등재해요. 해당 제품이 없으면 그 사실을 목록에 기록해요.
3. 03 검증필 암호모듈 목록: 02 목록의 제품에 탑재된 검증필 암호모듈을 검증번호·유효기간·알고리즘과 함께 등재하고 보안정책서 사본을 보관해요.
4. 04 검증필 암호모듈 적용 검토서: 기존 운영 제품은 최초 1회 소급 검토하고, 이후 신규 도입 건마다 계약 전에, 그리고 연 1회 정기로 작성해요.
5. 05 증적 수집 점검표: 제품·모듈별로 인증서 사본, 검증필 목록 조회 화면, 동작모드 설정 화면 등을 수집·보관해요.

## 3. 심사 대비 체크리스트

- [ ] VPN, 보안 USB, 호스트 자료유출 방지제품(암호화 저장 기능 보유 시) 등 중요자료 전송·저장에 사용하는 제품을 빠짐없이 식별해 02 목록에 등재했다.
- [ ] 검증필 암호모듈 탑재 필수 제품 유형을 국가 사이버보안 기본지침과 국가정보원 공지(IT보안인증사무국, 국가정보원, 국가사이버안보센터)로 확인했다.
- [ ] 검증필 암호모듈이 필수인 제품에는 검증필 암호모듈이 탑재된 제품만 도입했고, 탑재 모듈의 검증번호·유효기간을 03 목록에 기록했다.
- [ ] 해당 제품은 CC 인증 또는 보안기능 확인서를 획득한 제품이며, SSO 제품은 국가용 보호프로파일을 준수한 CC 인증 또는 보안기능 확인 제품이다.
- [ ] 검증필 암호모듈 유효기간과 CC 인증(보안기능 확인서) 유효기간을 각각 확인하고, 둘 중 하나라도 만료되면 해당 제품을 유효하지 않은 것으로 판정한다.
- [ ] 도입 전에 04 검토서로 필수 대상 여부와 검증·인증 유효성을 확인하고 정보보호 최고책임자 승인을 받는 절차가 있고 이행 기록이 있다.
- [ ] 연 1회 이상, 그리고 만료 {{90}}일 전에 두 유효기간을 점검해 갱신·대체 계획을 수립하고 결과를 02·03 목록에 반영했다.
- [ ] 운영 중인 제품이 검증필 암호모듈의 검증대상 동작모드로 동작하고 있음을 설정 화면 등 증적으로 확인했다.
- [ ] IaaS/PaaS 제공자가 제공하는 관리형 암호화 기능(키 관리 서비스, 스토리지 암호화 등)은 제공자 CSAP 인증과 계약으로 안전성을 확인했다.
- [ ] 중요자료 전송·저장용 암호화 제품을 도입하지 않은 경우 그 사실과 판단 근거를 02 목록에 기록했다.

## 4. 관련 산출물(다른 항목)

- 7.1.1 법적요구사항 준수: 국가 사이버보안 기본지침과 국가정보원 보안적합성 검증·암호모듈 검증 정책을 법적 요구사항 목록에 등재하고 준수 여부를 함께 점검해요.
- 11.1.4 네트워크 암호화: 운영자 원격 접속 등에 사용하는 VPN은 11.1.4 암호화 통신 채널 현황과 본 항목 02 목록에 함께 나타나야 해요.
- 12.3.1 암호 정책 수립: 검증필 암호모듈이 지원하는 국가표준 암호 알고리즘을 암호 정책의 알고리즘·키 길이 기준과 맞추고, 암호키 관리는 12.3.1 암호키 관리대장을 따라요.
- 13.1.2 인증 및 암호화 기능: 서비스에 직접 구현하는 암호화 기능의 알고리즘 선정과 연계해요.
- 14.1.2 도입 전산장비 안전성: CC 인증·보안기능 확인서 확인 절차와 증적을 공유해요. 중요자료 전송·저장 제품은 14.1.2의 보안기능 정보통신제품 목록과 본 항목 02 목록에 함께 나타나야 해요.

## 5. 양식 작성 규칙

- `{{ }}`로 표시한 자리표시자는 실제 값으로 바꿔요. 표의 빈 칸은 해당 값을 채워요.
- 서명이 필요한 문서는 서명본을 스캔해 보관하고, md 원본에는 서명본 보관 위치를 적어요.
- 문서를 개정하면 문서 정보 표의 버전과 개정 이력을 갱신하고, 목록 문서(02, 03)는 이전 버전을 삭제하지 않고 보관해요.
- 국가 사이버보안 기본지침 제20조(정보통신제품 도입)·제22조(검증필 암호모듈 운용 및 관리)는 비공개 지침이라 문서명과 조 번호만 인용하고, 필수 제품 유형·검증 요건 등 세부사항은 국가정보원이 공지한 보안적합성 검증 정책과 암호모듈 검증 정책(IT보안인증사무국 <https://www.itscc.kr>, 국가정보원 <https://www.nis.go.kr>, 국가사이버안보센터 <https://www.ncsc.go.kr)으로> 확인해요.
- 검증필 암호모듈·검증필 제품 목록과 유효기간은 조회 시점에 따라 달라지니, 심사 전과 정기 점검 때마다 IT보안인증사무국에서 다시 확인해요.
