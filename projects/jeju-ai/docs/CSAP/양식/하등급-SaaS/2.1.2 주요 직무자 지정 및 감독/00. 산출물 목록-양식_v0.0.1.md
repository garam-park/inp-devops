## 2. 권장 작성 순서

1. 01 주요 직무 기준: 중요 정보자산 유형과 주요 직무 기준, 지정 원칙과 절차를 정하고 정보보호 최고책임자 승인을 받아요.
2. 02 주요 직무 기술서: 직무별 취급 자산, 필요 최소 권한, 자격요건, 적정 인원을 정의하고 담당 부서장이 검토해요.
3. 05 주요 직무자 지정 신청서: 현재 주요 직무를 수행하는 인원을 부서별로 신청·검토·승인해요. 최초 일괄 지정도 개인 단위로 작성해요.
4. 03 주요 직무자 목록: 승인 결과를 시스템 계정·권한 현황과 대조해 작성하고, 대조 자료의 기준일을 기록해요.
5. 04 개인정보취급자 목록: 개인정보 취급이 ○인 인원을 개인정보처리시스템 권한 목록과 대조해 작성해요.
6. 06 주요 직무자 적정성 검토서: 반기마다 인사·시스템 자료와 전면 대조하고 결과를 03·04 목록에 반영해요.

## 3. 심사 대비 체크리스트

- [ ] 중요 정보자산을 취급하는 직무를 내부 기준으로 정의했고, 정보보호시스템 관리자·클라우드 콘솔 관리자·형상관리 관리자·네트워크 관리자·암호키 관리자를 빠뜨리지 않았다.
- [ ] 주요 직무자를 개인 단위로 신청·검토·승인 절차를 거쳐 공식 지정했고 승인 문서를 보관하고 있다.
- [ ] 주요 직무자 목록의 인원과 실제 시스템 계정·권한 보유자가 일치하며, 대조에 사용한 자료와 기준일을 기록했다.
- [ ] 퇴직·인사이동·업무 변경 시 지체 없이 권한을 회수하고 목록을 갱신하는 절차가 있고 해제 이력이 남아 있다.
- [ ] 직무별 적정 인원을 정했고 부서 단위 일괄 지정이나 부서 단위 권한 부여가 없다.
- [ ] 외부인력은 원칙적으로 지정에서 제외했고, 지정한 경우 관리 방안(계정 만료일, 감독자, 서약, 접근기록 검토)을 문서화하고 이행 기록이 있다.
- [ ] 개인정보를 취급하는 인원을 개인정보취급자로 지정했고, 권한 부여·변경·말소 기록을 3년 이상 보관하며 개인정보 보호 교육을 연 1회 이상 실시했다.
- [ ] 주요 직무자 교육 이수, 서약서, 접근기록 검토 등 관리·통제 이행 기록이 있다.
- [ ] 반기 1회 이상 적정성 검토를 수행하고 결과를 목록 버전에 반영했다.

## 4. 관련 산출물(다른 항목)

- 1.2.1 조직 구성: 정보보호 조직 구성 승인서와 정보보호 직무기술서에서 정한 정보보호 최고책임자·관리자·담당자를 주요 직무자 목록에 등재해요. 정보보호 조직 직무의 책임·자격요건은 1.2.1 직무기술서를 따라요.
- 2.3.2 교육 시행: 주요 직무자 직무별 보안 교육과 개인정보취급자 개인정보 보호 교육의 이수 기록을 통제 이행 증빙으로 활용해요.
- 10.1.2 접근기록 관리: 주요시스템과 개인정보처리시스템의 접근기록 검토 기록을 모니터링 증빙으로 활용하고, 개인정보취급자 접속기록 보관 기간(1년 또는 2년)을 맞춰요.
- 10.3.2 사용자 인증, 10.3.3 강화된 인증 수단 제공: 주요 직무자 계정에 다중 인증을 적용해요.
- 12.3.1 암호 정책 수립: 암호키 관리자 직무(KD-11)의 키 관리 절차를 암호 정책과 맞춰요.
- 14.3.3 데이터 유출 방지: 공공 가상자원·데이터에 접근하는 인력을 주요 직무자로 한정해요.

## 5. 양식 작성 규칙

- `{{ }}`로 표시한 자리표시자는 실제 값으로 바꿔요. 표의 빈 칸은 해당 값을 채워요.
- 직무 코드 KD-01~KD-11은 예시예요. 조직에 없는 직무는 삭제하고, 추가 직무는 01 기준 5항과 02 기술서에 함께 신설해요.
- 서명이 필요한 문서는 서명본을 스캔해 보관하고, md 원본에는 서명본 보관 위치를 적어요.
- 목록 문서(03, 04)는 버전을 올릴 때 이전 버전을 삭제하지 않고 보관해서 특정 시점의 지정 현황을 확인할 수 있게 해요.
- 법령 인용은 개인정보 보호법 제28조(법률 제20897호, 2025. 10. 2. 시행), 개인정보의 안전성 확보조치 기준 제4조·제5조·제8조(개인정보보호위원회고시 제2026-9호, 2026. 7. 1. 시행) 기준이에요. 법령·고시가 개정되면 국가법령정보센터에서 조문을 다시 확인해요.
- 접속기록 점검 주기는 현행 고시가 내부 관리계획으로 정하도록 위임하고 있어서, 양식의 "월 1회 이상"은 당사 내부 기준이에요. 내부 관리계획과 다르면 내부 관리계획 기준으로 맞춰요.
