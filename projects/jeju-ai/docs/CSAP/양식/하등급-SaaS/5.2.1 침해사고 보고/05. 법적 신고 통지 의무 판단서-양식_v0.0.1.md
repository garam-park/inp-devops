## 3. 교차 확인

신고와 통지가 서로를 대체하지 않는다는 점을 확인한다. 하나라도 X이면 2항을 다시 판단한다.

- [ ] 이용자·정보주체 통지(B·C·E·F)를 결정했다면, 관계기관 신고(A·D·G) 대상 여부를 각각 별도로 판단했다.
- [ ] 관계기관 신고(A·D·G)를 결정했다면, 이용자·정보주체 통지(B·C·E·F) 대상 여부를 각각 별도로 판단했다.
- [ ] 유출된 정보에 고유식별정보(운전면허번호 등) 또는 민감정보가 포함되었는지 항목 단위로 확인했고, 포함되면 건수와 무관하게 G를 신고로 판단했다.
- [ ] 외부 불법 접근에 의한 유출이면 건수와 무관하게 G를 신고로 판단했다.
- [ ] 개인정보가 아닌 이용자 정보의 유출도 C와 D의 대상임을 확인했다.
- [ ] 정보통신망법 신고(A)와 개인정보 보호법 신고(G)는 별개의 의무임을 확인했다.
- [ ] 수탁 개인정보가 관련되면 이용 기관(H)에 통보하고 이용 기관의 신고·통지에 필요한 정보를 제공하기로 했다.
- [ ] 사실이 모두 확인되지 않아도 기한 내에 확인된 내용으로 먼저 신고·통지하고 추가 확인 시 추가 신고·통지하기로 했다.
