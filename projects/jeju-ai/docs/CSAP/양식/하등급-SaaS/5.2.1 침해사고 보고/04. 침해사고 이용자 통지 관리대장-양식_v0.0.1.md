## 1. 이용 기관 통지 연락망

- 이용자 통지(B·C·E)는 이용 기관마다 한 행씩 기록하거나, 같은 통지문을 일괄 발송한 경우 대상 기관 목록을 첨부하고 한 행으로 기록한다.
- 관계기관 신고 병행 열이 "해당 없음"이면 양식 05에서 신고 비대상으로 판단한 근거를 비고에 적는다. 통지만 하고 관계기관 신고를 누락하지 않도록 이 열을 비워 두지 않는다.
- 발생 원인을 제외하고 먼저 통지한 경우 원인 확인 후 추가 통지를 새 행으로 기록한다.

## 3. 통지 내용 확인

발송 전에 통지 구분별 필수 항목이 모두 포함되었는지 확인하고 결과를 2항의 비고에 적는다.

| 구분 | 확인 항목 | 포함 |
| --- | --- | --- |
| B·C·E(이용자) | 발생 내용 | {{○ / X}} |
| B·C·E(이용자) | 발생 원인(미확인 시 "확인 중, 확인되면 즉시 추가 통지" 명시) | |
| B·C·E(이용자) | 당사의 피해 확산 방지 조치 현황 | |
| B·C·E(이용자) | 이용자의 피해 예방 또는 확산 방지 방법 | |
| B·C·E(이용자) | 담당부서 및 연락처 | |
| F(정보주체) | 유출등이 된 개인정보의 항목 | |
| F(정보주체) | 유출등이 된 시점과 그 경위 | |
| F(정보주체) | 정보주체가 할 수 있는 피해 최소화 방법 | |
| F(정보주체) | 당사의 대응조치 및 피해 구제절차 | |
| F(정보주체) | 피해 신고 등을 접수할 수 있는 담당부서 및 연락처 | |
| 위탁자 통보 | 유출 항목·규모·경위·조치 현황, 이용 기관의 신고·통지에 필요한 정보, 당사 협조 창구 | |

## 4. 통지 방법별 증적 기준

| 통지 방법 | 보관할 증적 | 유의 사항 |
| --- | --- | --- |
| 전화·휴대전화 | 통화 일시·상대·내용 기록, 가능하면 후속 전자우편 | 기록이 남는 방법으로 다시 통지한다 |
| 전자우편 | 발송 원문, 발송 로그, 수신 확인 | 대상 목록을 첨부한다 |
| 문자메시지 | 발송 결과 보고서 | 상세 내용은 전자우편·게시로 보완한다 |
| 우편 | 발송 대장, 등기 번호 | |
| 서비스 접속화면 게시 | 게시 시작·종료일의 화면 캡처, 게시 문안 | 15일 이상 게시(클라우드컴퓨팅법 시행령 제17조제2항) |
| 홈페이지 게시(정보주체 통지 갈음) | 게시 시작·종료일의 화면 캡처, 갈음 사유 기록 | 연락처를 알 수 없는 등 정당한 사유가 있을 때만, 30일 이상 게시(개인정보 보호법 시행령 제39조제3항) |
| 일간신문 공고(이용자 통지 갈음) | 공고 지면, 과학기술정보통신부장관 통보 문서 | 천재지변 등 불가피한 사유가 있을 때만(시행령 제17조제3항·제4항) |
