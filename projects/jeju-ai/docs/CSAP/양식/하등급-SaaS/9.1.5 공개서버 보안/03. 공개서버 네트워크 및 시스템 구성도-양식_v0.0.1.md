## 2. 네트워크 구성도

```mermaid
flowchart TB
    USER["이용자·이용 기관(인터넷)"]
    ADMIN["운영자(사내망·재택)"]

    subgraph PROVIDER["IaaS/PaaS 제공자 관리 영역(물리 보안·하이퍼바이저)"]
        DDOS["DDoS 기본 방어"]
        subgraph VPC["당사 VPC"]
            subgraph DMZ["DMZ(퍼블릭 서브넷)"]
                WAF["웹 방화벽(WAF)"]
                LB["로드밸런서(TLS 1.2 이상 종단)"]
                WEB["웹서버·API 게이트웨이(PUB-SRV-01)"]
                DIST["배포 서버(PUB-SRV-02)"]
            end
            subgraph APP["내부 네트워크 - 앱(프라이빗 서브넷)"]
                WAS["WAS(APP-01)"]
            end
            subgraph DB["내부 네트워크 - DB(프라이빗 서브넷)"]
                DBS["DB(DB-01)"]
                CACHE["캐시"]
            end
            subgraph MGMT["관리망(프라이빗 서브넷)"]
                BASTION["접근통제솔루션·배스천"]
                LOG["로그 저장소·SIEM"]
            end
        end
    end

    USER -->|"443"| DDOS --> WAF --> LB
    LB -->|"443"| WEB
    LB -->|"443"| DIST
    WEB -->|"앱 포트"| WAS
    WAS -->|"DB 포트"| DBS
    WAS --> CACHE
    ADMIN -->|"VPN + 다중 인증"| BASTION
    BASTION -->|"22(세션 기록)"| WEB
    BASTION -->|"22(세션 기록)"| DIST
    BASTION --> WAS
    WEB -. "로그 전송" .-> LOG
    DIST -. "로그 전송" .-> LOG
    WAF -. "로그 전송" .-> LOG
    BASTION -. "세션 기록" .-> LOG
```

- 실선은 서비스·관리 통신, 점선은 로그 전송을 뜻한다. 화살표 방향은 통신을 개시하는 방향이다.
- DMZ에서 DB로 직접 향하는 경로는 두지 않는다. 불가피하게 존재하면 5항 매트릭스에 사유와 보완 통제를 기록한다.
- 제공자 관리 영역(물리 시설, 하이퍼바이저, DDoS 기본 방어)은 제공자 인증·계약으로 확인하며, 당사는 VPC 내부 구성을 책임진다.
- 실제 구성과 다르면 노드·연결을 수정하고, PaaS 실행 환경을 쓰면 해당 노드를 관리형 서비스명으로 바꾼다.
