## 4. 판정 기준

- 각 케이스는 기대 결과와 일치하면 통과, 일치하지 않으면 실패로 판정하고 결함으로 등록한다.
- 2항의 모든 보안 요구사항이 하나 이상의 케이스로 시험되고, 모든 케이스가 통과(또는 결함 조치 후 재시험 통과)해야 시험을 종료한다.
- 결함 조치와 재시험, 운영 반영 판정은 양식 04. 보안 시험 결과서에 기록한다.
