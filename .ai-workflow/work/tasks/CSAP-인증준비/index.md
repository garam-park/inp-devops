## 대기를 푸는 선행 조건

대기 71건은 거의 모두 아래 조건으로 풀린다.

1. NCP 공공기관용 운영 환경 구축: NKS·Cloud DB·Object Storage·VPC·ACG·LB·SSL VPN·배스천. 공공 콘솔 실측 5건(ADR D4)
2. jeju-ai-saas-be 의 인증·RBAC·감사 로그·DB 구현 (제품 설계안 2단계)
3. 로그 수집·보존 경로 (관리형 로그 또는 별도 버킷)
4. 제품 Helm chart 와 NetworkPolicy (gis-sass chart 이식)
5. 결정 사항: KCMVP 적용 방식, TLS 종단 위치, VPN 제품

### 결정 (사람)

1. jeju-ai-saas-be/fe 의 브랜치 보호와 PR 리뷰를 어떻게 할지 정한다. 비공개 저장소라 free 플랜에서는 설정할 수 없고 API 가 403 을 낸다. 지금은 PR 0건이고 develop 에 직접 병합한다. 선택지는 요금제 상향, 공개 전환, 절차로 대신하기다.
2. 야간 k6 의 api p95 가 309–312 ms 로 목표 300 ms 를 넘었다. 기준을 유지할지 올릴지 정한다. 시험 도구의 지연일 수도 있지만 확인하지 않았다.
3. 하등급 조건과 설계 스키마가 충돌하는지 확인한다. 설계안의 `users.name`·`dept` 와 `audit_events.user_name` 에 성명이 저장된다.
4. 클러스터 내부 구간(Ingress↔파드, web↔api)이 평문이다. 예외로 둘지, CNI 암호화로 막을지 정한다. CISO 승인이 필요하다.
5. TLS 종단 위치를 NCP LB 로 할지 Ingress 로 할지, 검증필 암호모듈(KCMVP)을 어떻게 적용할지, VPN 제품을 무엇으로 할지 정한다.
6. 관리자 기능을 분리할지 정한다. 선택지는 `/api/admin/` 접두어, 관리자 전용 호스트, 지금처럼 IP 허용 목록이다. `service` 역할이 이용 기관 사람인지도 함께 정한다.
7. 완전삭제 기능을 설계에 추가한다. 계약 종료 기관의 일괄 삭제, 계정 실삭제, 사고 기록 실삭제가 대상이다.
8. 설계에 없는 인증 기능을 추가한다. TOTP, 동시 세션 제한, 세션 시간, 불법 로그인 경고, 내보내기 사유 입력이 대상이다.
9. 운영 버킷명을 정한다. 설계안은 `subsidence-prd`, 코드와 공통 기준은 `jeju-ai-saas` 다.
10. GitHub(미국)를 거치는 배포 지시가 14.2.1 사례 2 에 해당하는지 해석한다. 국외 리전 생성 차단 수단이 없는 것을 계정·권한 한정으로 대신해도 인정되는지도 함께 판단한다.

### 문서 정합 (내부에서 고칠 것)

- 세션 시간이 묶음마다 다르다. 공통 기준은 30분이고, 13.1.2·13.2.1 은 관리자 15분, 9.1.5 는 관리 접속 10분이다. 하나로 정해 공통 기준 §3.1 에 넣는다.
- 자원 태그가 다르다. 14.3.3 은 `service=jeju-ai-saas · env=prd`, 14.3.5 는 `service=jas · env=prod · csap-zone=public` 이다.
- 정책서 승인자가 다르다. 양식은 CISO 검토 + 대표이사 승인이고, 공통 기준 §2 는 CISO 승인이다.
- 임계치 단계가 다르다. 공통 기준 §3.5 는 2단계(70/85)이고 6.2.1 은 3단계(70/85/95)다.
- "인지 즉시 통지"를 1시간 이내로 해석했다. 이 값을 공통 기준 §3.7 에 넣는다.
- 공통 기준 §1 의 브이월드 서술을 고친다. 실제로는 브라우저가 타일을 직접 받는다.
- 묶음마다 새로 정한 당사 기준값(보고/ 각 파일의 "새 기준값")을 공통 기준 §3 에 옮긴다.
- 제품 설계안 `docs/design/jeju-subsidence-ai/02` §4.2 는 운영을 "지자체 망분리"로 가정한다. ADR 은 NCP 공공 인터넷망이다. 설계안을 고친다.

### 코드·설정 개선 후보

- `mise.toml` 의 trivy 가 `--exit-code 0` 이라 배포를 막지 않는다. FE Dockerfile 에는 `apk upgrade` 가 없다.
- web 에 COEP·COOP·CORP 헤더가 없다(ZAP Low 3건). api 와 web 의 X-Frame-Options·HSTS 값이 다르다.
- Fastify 기본 오류 처리기가 500 응답에 내부 메시지를 실을 수 있다. `/api/openapi.json` 이 공개돼 있다.
- `api/src/storage.ts` 기본값이 `us-east-1`·`localhost` 다. 값이 없으면 기동하지 않게 바꾼다.
- 별표 3 보안약점과 semgrep 규칙의 매핑표가 없다.
