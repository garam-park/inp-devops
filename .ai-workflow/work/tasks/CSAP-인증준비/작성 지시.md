# 작성 에이전트 공통 지시

당신은 CSAP(클라우드 보안인증) 하등급 SaaS 산출물 양식을 실제 내용으로 채우는 작성자다. 작업 공간 루트는 /Users/garam/ops/inp/ws 이다.

## 먼저 읽을 것
1. `.ai-workflow/work/tasks/CSAP-인증준비/공통 기준.md` — 공통 값, 당사 내부 기준값, 작성 규칙(§4), 상태 판정 규칙. 단일 출처다. 여기 없는 값을 새로 정하면 보고서에 적는다.
2. 담당 통제항목의 해설서 (`projects/jeju-ai/docs/CSAP/해설서/하등급-SaaS/<분류>/<통제항목>.md`).
3. 담당 양식 전부 (`projects/jeju-ai/docs/CSAP/양식/하등급-SaaS/<통제항목>/`).
4. 시스템 사실이 더 필요하면 공통 기준 §6 경로를 직접 읽는다. 추측으로 채우지 않는다.

## 할 일
- 각 양식을 구조 그대로 두고 자리표시자를 채운 작성본으로 만든다. 공통 기준 §4 규칙을 그대로 따른다.
- 먼저 `.ai-workflow/work/tasks/CSAP-인증준비/10 작성중/<통제항목 폴더명>/NN. <문서>.md` 에 쓰고, 끝나면 상태 판정에 따라 `20 작성완료/<폴더>/` 또는 `11 대기중/<폴더>/` 로 `mv` 한다. 끝났을 때 `10 작성중` 에 당신 몫 파일이 남으면 안 된다.
- 대기중 문서는 front matter 에 `상태: 대기중`, `대기 사유:` 를 넣고 근거 블록 아래 `> [!warning] 대기` 블록에 "무엇이 생기면 어느 칸을 채울 수 있는지"를 적는다.
- 양식의 절·표·행을 삭제하지 않는다. 표 행은 당사 시스템에 맞게 실제 항목으로 채우고, 해당 없으면 "해당 없음 — 사유".
- 비기술 양식(공통 기준 §5)은 쓰지 않고, 00 산출물 목록에서 "비기술 — 별도 작성(TODO 목록)" 으로 표시한다.
- 원본 양식·해설서·gis-sass·apps 아래 파일은 수정하지 않는다. 쓰기는 `.ai-workflow/work/tasks/CSAP-인증준비/` 아래 당신 몫 폴더만. 공통 기준.md · index.md 는 수정하지 않는다.
- 질문하지 말고 공통 기준에 따라 판단하고, 판단은 보고서에 남긴다.
- Bash(cat/sed)로 읽고 Write 로 쓴다. 한 번에 한 파일씩 완성한다. 담당 전부를 끝내기 전에 멈추지 않는다.

## 끝나면 보고 (이 형식 그대로)
1. 문서별 표: `| 폴더 | 파일 | 최종 폴더 | 남은 {{}}(비기술 의존) | 남은 {{}}(개발·인프라 대기) | 대기 사유 요약 |`
2. 공통 기준에 없어 새로 정한 당사 기준값 (항목, 값, 문서)
3. 공통 기준과 어긋나거나 해설서 요구를 현 설계로 충족할 수 없다고 본 지점
4. 검증: 당신 몫 파일 수(`find`)와 파일별 `grep -c '{{'`
