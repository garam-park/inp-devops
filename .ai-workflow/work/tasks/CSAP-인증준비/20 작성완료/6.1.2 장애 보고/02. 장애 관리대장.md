## 2. 장애 관리대장

장애를 인지하면 즉시 등재하고, 복구·통지·보고가 끝날 때마다 해당 열을 갱신한다. 담당 부서가 자체 조치로 복구한 3급 장애도 등재하고 정보보호 최고책임자 보고 일시를 기록한다. 등급은 1급(서비스 전면 중단) · 2급(주요 기능 중단) · 3급(일부 저하)이다(01. 장애 대응 및 보고 절차 4항, 공통 기준 §3.7).

| No | 장애번호 | 발생일시 | 인지일시 | 인지 경로 | 복구일시 | 중단 시간(분) | 24시간 내 누적 중단(회 / 분) | 영향 서비스·기능 | 영향 이용 기관(수, 공공기관 포함 여부) | 등급 | 사전 예고 | 원인 구분 | 원인 요약 | 조치 요약 | 통지 대상 판정 | 판정 근거 | 이용자 통지(1차 일시 / 원인 추가 통지 일시) | 내부 보고(경영진 일시 / 이해관계 부서 일시) | 관계기관 신고·통보 | 침해사고·유출 동반 | 보고서 번호 | 담당 | 비고 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 기록 없음(기준일 2026-10-20 현재) | | | | | | | | | | | | | | | | | | | | | | 운영 환경 구축 전, 서비스 미개시 |
| 2 | | | | | | | | | | | | | | | | | | | | | | | |
| 3 | | | | | | | | | | | | | | | | | | | | | | | |
| 4 | | | | | | | | | | | | | | | | | | | | | | | |
| 5 | | | | | | | | | | | | | | | | | | | | | | | |

- 장애번호는 `FLT-YYYY-NNN`(연도-일련번호)으로 부여하고 03. 장애 보고서(`FLT-RPT-YYYY-NNN`), 04. 이용자 통지문, 05. 신고 및 통지 내역 관리대장, 14.1.4 양식 04·05 에서 같은 번호를 쓴다.
- 각 열의 기입 값: 인지 경로(모니터링 / 이용자 신고 / 제공자 통지), 영향 서비스·기능(로그인, 지도·위험도 조회, 레이어 표시, 사고 기록, 데이터셋 올리기·빌드, 내보내기), 등급(1 / 2 / 3), 사전 예고(X / ○), 원인 구분(당사 / IaaS·PaaS 제공자 / 외부 연계 / 이용 기관), 통지 대상 판정(법정 / 계약 / 내부(1·2급) / 비대상), 판정 근거(연속 n분(10분 이상) / 24시간 내 n회 합계 n분(15분 이상) / 계약 n분 / 1·2급 내부 기준 / 기준 미달), 침해사고·유출 동반(X / 침해사고 / 이용자 정보 유출 / 개인정보 유출).
- 중단 시간은 01. 장애 대응 및 보고 절차 3항의 정의에 따라 산정하고, 산정 근거(모니터링 로그, 이용자 신고 시각)를 보고서에 첨부한다.
- 통지 대상 판정이 "비대상"이면 판정 근거에 계측한 중단 시간과 계약 기준을 적어, 심사 시 판정 근거를 보일 수 있게 한다.
- 이용자 통지 열의 원인 추가 통지가 "해당 없음"인 경우는 1차 통지에 원인이 포함된 경우에 한한다.

## 3. 24시간 내 반복 중단 판정 보조표

첫 중단 사고가 발생한 때부터 24시간 이내에 중단이 다시 발생하면 아래 표로 누적 중단 기간을 계산한다. 합계가 15분 이상이면 법정 기준 2에 해당한다.

## 4. 통지 대상 판정 규칙(요약)

| 조건 | 판정 |
| --- | --- |
| 사전 예고된 계획 중단 | 비대상(대장 기록과 내부 보고는 수행) |
| 연속 중단 10분 이상 | 법정 대상(시행령 제16조제1호) |
| 24시간 이내 2회 이상 중단, 합계 15분 이상 | 법정 대상(시행령 제16조제2호) |
| 이용 기관 계약상 기준 기간 이상 | 계약 대상(해당 이용 기관, 01. 절차 9항) |
| 침해사고 또는 이용자 정보 유출 동반 | 중단 시간과 무관하게 대상. 관계기관 신고 여부를 별도 판정(01. 절차 8.5항) |
| 위 어느 것도 아님 | 비대상(중단 시간과 근거 기록). 단 1·2급 장애는 당사 내부 기준으로 인지 후 1시간 이내 통지한다(01. 절차 8.1항) |

## 5. 현행화 규칙

- 장애 인지 즉시 등재하고, 복구·통지·보고 완료 시 1영업일 이내에 갱신한다.
- 매월 1항 현황 요약을 갱신하여 정보보호 최고책임자에게 보고한다.
- 반기마다 05. 신고 및 통지 내역 관리대장, 03. 장애 보고서와 대조하여 통지·보고 누락 건이 없는지 확인하고 결과를 비고에 기록한다.
- 대장의 모든 버전은 3년 이상 보관한다(사내 문서 저장소 `CSAP/장애기록/관리대장/`).
