# 11.1.5 네트워크 분리 산출물 목록

하등급 SaaS 인증 기준 11.1.5(제공자 관리 영역·이용자 서비스 영역·이용자 간 서비스 영역의 물리적 또는 논리적 네트워크 분리, 영역 간 접근통제)를 충족하기 위해 준비하는 산출물과 각 문서의 용도·작성 상태를 정리한다. 대상 서비스는 지반침하 스마트관리 시스템(제주 GEO-AI 지반침하 SaaS)이다(기준일 2026-10-20, 운영 환경 구축 전).

## 2. 권장 작성 순서

1. 01 네트워크 분리 관리 지침: 분리 원칙, 영역 구분, 인터넷 접근 제한·자료전송·우회 경로 통제, 검토 주기를 정하고 정보보호 최고책임자 승인을 받는다.
2. 02 네트워크 영역별 분리 기준: 영역별 배치 기준과 분리 구현 수단, 환경 분리·이용 기관 분리 기준을 정한다. 영역 명칭은 9.1.5 구성도와 동일하게 맞춘다.
3. 03 네트워크 분리 구성도: NCP 콘솔의 계정·VPC·서브넷·연계 구성을 조회해 영역 단위 구성도와 접근통제 요약을 작성한다.
4. 04 네트워크 분리 정책 준수 검토서: 분기마다(그리고 구조 변경 시) 실제 구성과 대조 검토하고 기록을 누적한다.
5. 05 증적 수집 점검표: 심사 전에 콘솔 설정·시험 결과 화면을 수집해 보관 위치를 기록한다.

## 3. 심사 대비 체크리스트

기준일 2026-10-20 현재 충족 여부다.

- [ ] 네트워크 영역(DMZ, 내부 - 앱, 내부 - DB, 관리망, 개발·시험)을 분리 기준과 함께 문서화했고, 실제 클라우드 구성과 일치한다. — 문서화 완료(01·02), 운영 구성 미구축
- [ ] 운영 네트워크와 개발·시험 네트워크가 계정 또는 VPC 단위로 분리되어 있고, 동일 VPC 내 서브넷 구분만으로 분리하지 않았다. — 설계상 물리 분리(NCP 공공 대 사내 `dev0`), 운영 계정 미생성으로 증적 없음
- [ ] 개발·시험 환경과 운영 환경 간 피어링·라우팅이 없고, 개발 서버에서 운영 DB로 접속할 수 없다. — 운영 DB 미생성으로 접속 시험 전
- [ ] 이용자의 중요정보가 저장된 DB가 Private 서브넷(데이터 영역)에만 있고, Public 서브넷 배치·공인 IP 할당이 없다. — Cloud DB 미생성
- [ ] DMZ(진입 영역)를 경유한 내부망 접근이 통제되고, 진입 영역에서 DB로 직접 향하는 경로가 없다. — 서비스 NetworkPolicy 미작성
- [ ] 진입 영역·내부망 서버에서 인터넷으로의 불필요한 직접 접속이 차단되고, 아웃바운드는 NAT 경유 허용 목적지로만 한정된다. — 운영 미구축
- [ ] 클라우드 시스템 운영 인력의 접속 경로(관리망)가 분리되어 있고 SSL VPN·배스천(다중 인증)을 경유해서만 접근한다. — SSL VPN·배스천 미구축
- [ ] 외부 접근이 필요 없는 운영자용 서비스 관리 기능이 이용자 기능과 분리되어 인터넷에 노출되지 않는다. — 관리자 기능 미구현, 같은 호스트의 경로별 IP 제한 방식이라 관리자 API 접두어 정리 필요(04 발견 2)
- [ ] 이용 기관 간 서비스 영역이 분리되어 있고 격리 시험 기록이 있다. — 전용 배포 기준 수립, 이용 기관 1곳이라 격리 시험 전
- [ ] 망간 자료전송 통제 방안이 있고 승인·전송 기록이 보관된다. — 방안은 01 8항, 전송 이력 없음
- [ ] 우회 경로(미등재 공인 IP, 임의 터널·피어링, 배스천 미경유 관리 포트)를 모니터링하고 차단·조치 기록이 있다. — 흐름 로그·감사 로그 미구성
- [ ] 네트워크 분리 정책 준수 여부를 분기 1회 이상, 구조 변경 시 검토한 기록(04)이 누적되어 있다. — 첫 회차(수시)만 있음
- [ ] 물리 네트워크·하이퍼바이저 격리는 제공자 책임임을 책임공유모델로 명시하고 제공자 CSAP 인증서·계약 사본을 보관하고 있다. — 01 4항에 명시, 인증서·계약서 사본 미확보

## 4. 관련 산출물(다른 항목)

- 9.1.5 공개서버 보안: 공개서버 네트워크 및 시스템 구성도와 영역 명칭·대역·ACG 체계를 공유한다. 서버·규칙 단위 통신 허용 매트릭스는 JAS-9.1.5-03 에서 관리한다.
- 11.1.4 네트워크 암호화: 분리된 영역 간·외부 구간 통신의 암호화 기준을 맞춘다.
- 10.1.2 접근기록 관리: 흐름 로그·네트워크 구성 변경 감사 로그를 접근기록 관리 대상에 포함한다.
- 2.1.2 주요 직무자 지정 및 감독: 네트워크 구성 변경 권한 보유자(네트워크 관리자)를 주요 직무자 목록에 등재한다.
- 13.2.1 구현 및 시험: 이용 기관 격리 시험을 릴리스 전 보안 시험 항목과 연계한다.
- 14.2.1 물리적 위치 및 영역분리, 14.3.5 영역분리: 공공기관 이용 시 국내 리전 위치와 영역 분리 요건(공공 고객용 인스턴스를 민간과 공유하지 않음)을 구성도에 반영한다.

## 5. 작성 규칙

- 개발·인프라 미완으로 채우지 못한 칸은 `대기:` 로 시작하는 자리표시자로 두고, 그 문서 머리의 대기 블록에 무엇이 생기면 채울 수 있는지 적었다. 사람 이름·승인일은 1.2.1 조직 구성 확정 후 일괄 치환한다.
- 서명이 필요한 문서는 서명본을 스캔해 사내 문서 저장소 `CSAP/서명본/11.1.5/` 에 보관하고, md 원본에는 서명본 보관 위치를 적는다.
- 문서를 개정하면 문서 정보 표의 버전과 개정 이력을 갱신한다. 기록 문서(03, 04)는 이전 버전을 삭제하지 않고 3년 보관한다. 검토서(04)는 회차마다 `JAS-11.1.5-04-<연도>-<회차>` 번호로 새로 만든다.
- 법령 인용은 개인정보의 안전성 확보조치 기준 제6조(접근통제)·제6조의2(인터넷망의 차단 조치 등)(개인정보보호위원회고시 제2026-9호, 2026. 7. 1. 시행) 기준이다. 고시가 개정되면 국가법령정보센터에서 조문을 다시 확인한다.
- 준수 검토 주기(분기 1회)는 해설서 예시를 따른 당사 기본값이다. 조정하면 01 지침과 04 검토서를 함께 고친다.
- VPC, Subnet, ACG, Network ACL, NAT Gateway, SSL VPN 은 NCP 서비스 명칭이다. 공공 영역 콘솔의 실제 명칭과 다르면 구축 시 맞춘다.
