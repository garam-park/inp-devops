## 1. 변경 개요

| 항목 | 내용 |
| --- | --- |
| 변경 요청자(소속·성명) | 개발 책임자 {{개발 책임자 성명}} |
| 대상 시스템·기능 | web(nginx 화면 응답), api(모든 응답) |
| 변경 사유 | 취약점 예방 — 품질·보안 게이트 정비(CSAP 준비). 전송 구간 HTTPS 강제(HSTS)와 클릭재킹·MIME 추측·정보 노출 방지 헤더 부재 |
| 변경 내용 요약 | web 화면 응답에 CSP · HSTS(1년) · `X-Content-Type-Options: nosniff` · `X-Frame-Options: DENY` · `Referrer-Policy` · `Permissions-Policy` 를 붙이고 nginx 버전 노출을 끈다(`server_tokens off`). api 모든 응답에 `@fastify/helmet` 기본 헤더(CSP 제외, HSTS 1년 포함)를 붙인다 |
| 관련 설계서·반영표 | 제품 설계안 04 §11, JAS-13.1.2-03(6항 ENC-T-01 · SEC-C-03 · SEC-C-04) |
| 관련 커밋·PR(PR 없음 — 하단 차이 참조) | `jeju-ai-saas-fe` `5dfe5dc`(build(nginx): send security headers on page responses, hide server version) → `develop` 병합 `7e3d70a`. `jeju-ai-saas-be` `9823c1d`(API 보안 응답 헤더 추가) → `develop` 병합 `589ac14` |

## 2. 변경 상세 내용

| 구분 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 설정(web `nginx.headers.conf` · `nginx.conf.template`) | 보안 응답 헤더 없음, `Server` 헤더에 nginx 버전 노출 | 화면 location(`/assets/` · `/`)마다 보안 헤더 6종 include(`always`, 오류 응답 포함). CSP `default-src 'self'` 기반(외부 허용은 `img-src https://api.vworld.kr` 하나). `server_tokens off`. `/api/` 프록시 응답에는 덧붙이지 않음(이중 헤더 방지) |
| 로직(api `src/app.ts`) | 보안 응답 헤더 없음 | `@fastify/helmet` 등록(`contentSecurityPolicy: false`) — nosniff · X-Frame-Options SAMEORIGIN · Referrer-Policy no-referrer · HSTS `max-age=31536000; includeSubDomains` · CORP/COOP same-origin 등 |
| 시험(web `e2e/headers.spec.ts`, api `test/app.test.ts`) | 없음 | 응답 헤더가 설정 파일과 글자 단위로 같은지, 장면 전부에서 CSP 위반 0, api 응답 종류(200 · 스트림 · 304 · 400 · 404)마다 헤더가 붙는지 단언 |

## 4. 보안 요구사항 반영·시험 확인

영향이 있는 요구사항별로 반영 내용과 시험 결과를 기록한다. 취약 프로토콜 비활성 확인과 계정 잠금 동작 확인은 관련 변경 시 생략하지 않는다(본 건은 프로토콜 설정·로그인을 바꾸지 않아 해당 없음).

| 요구사항 ID | 반영 내용 | 시험 방법 | 시험 결과 | 시험자 | 시험일 |
| --- | --- | --- | --- | --- | --- |
| ENC-T-01 | web · api 응답에 HSTS 1년 | web: 야간 stack 잡 `e2e/headers.spec.ts`(nginx 이미지에 Playwright), api: 단위 테스트 '보안 헤더' | 적합 — headers.spec 14건 통과(러너, FE nightly 실행 39381998452), api 단위 테스트 통과(BE CI 실행 39375973207) | {{개발 책임자 성명}} | 2026-10-20 |
| SEC-C-03 | 헤더를 직접 만들지 않고 `@fastify/helmet` 사용 | 코드 리뷰, semgrep | 적합 — semgrep 0건(BE 225규칙/25파일, FE 74규칙/74파일) | {{개발 책임자 성명}} | 2026-10-20 |
| SEC-C-04 | nginx 버전 노출 제거(`server_tokens off`) | ZAP 기준 검사(web), ZAP API 검사(api) | 적합 — High · Medium 0. web 은 Low 3종(COEP · COOP · CORP 헤더 없음) 지적, api 는 Info 만 | {{정보보호 담당자 성명}} | 2026-10-20 |

- 부적합 항목은 조치 완료 전 배포하지 않는다. 조치 내용: 부적합 없음. web ZAP Low 3종(Cross-Origin-*-Policy)은 위험 수용하지 않고 다음 헤더 변경 시 검토 대상으로 둔다(차단 기준 High).
