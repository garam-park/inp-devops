# 14.3.3 데이터 유출 방지 산출물 목록

하등급 SaaS 인증 기준 14.3.3(공공 데이터의 국외 유출 차단, 데이터 저장 위치의 국내 제한과 물리적 위치 확인·추적을 위한 기술적 방안·로그정보 제공)을 충족하기 위해 준비할 산출물과 각 문서의 용도를 정리한다. 당사는 CSAP 인증을 받은 IaaS(네이버 클라우드 플랫폼 공공기관용)의 국내 리전을 이용하는 SaaS 제공자이므로 데이터센터의 국내 소재는 제공자 인증·계약으로 확인하고, 당사 책임 범위인 국내 리전 한정 설정, 국외 생성·복제 차단, 위치 추적·검토, 이용 기관 증적 제공을 산출물로 증명한다.

## 2. 권장 작성 순서

1. 01 공공 데이터 국외 유출 방지 지침: 국내 위치 제한·국외 유출 차단 원칙과 기술적 보호조치, 검토·증적 제공 기준을 정하고 정보보호 최고책임자 승인을 받는다.
2. 05 증적 수집 점검표: 리전 설정, 국외 생성·복제 차단 정책, 접근 권한 목록, 위치 조회 화면 등 현재 설정 증적을 수집해서 상태를 확인한다.
3. 02 공공 데이터 저장 위치 관리대장: 수집한 증적을 근거로 데이터 유형별 저장 위치와 외부 연동의 데이터 위치를 목록으로 작성한다.
4. 04 물리적 위치 증적 제공 관리대장: 이용 기관에 제공할 표준 증적 꾸러미와 제공 절차를 정하고 최신 상태로 준비한다.
5. 03 데이터 물리적 위치 검토서: 반기마다 실제 자원·설정과 대장을 전면 대조하고 결과를 02 대장에 반영한다.

## 3. 심사 대비 체크리스트

- [ ] 공공 데이터의 국외 유출 방지를 위한 정책·지침을 수립하고 승인받았다. — 01 작성 완료, 승인 전(1.2.1 조직 구성 후 서명)
- [ ] 공공 서비스의 모든 데이터·백업·가상자원이 국내 리전에만 위치하고, 국외 리전에 가상자원을 생성할 수 없도록 기술적 차단 정책이 적용되어 있다. — 미충족: 2026-10-21 KR 리전 `KR-1` 존에 VPC·NAT·NKS 를 1차 구축했고(Cloud DB·앱 버킷 미구축), 공공기관용 영역의 리전은 `KR`(수도권)·`KRS`(남부권) 두 곳임을 확인했다(2026-10-21 `getZoneList`). 차단 정책 증적은 미수집
- [ ] 데이터·백업의 국외 복제·복사 설정이 없고, 외부 연동 서비스(CDN, 모니터링, 오류 수집, 메일 발송 등)로 공공 데이터가 국외에 저장·전송되지 않음을 점검했다. — 설계·코드 기준 점검 완료(02 4항: CDN·오류 수집·메일 없음, 브이월드 국내), 운영 설정 실측 전. GHCR(국외, 데이터 없음) 전환 대기
- [ ] 서비스의 데이터 저장 위치가 국내로 고정되어 있음을 이용 계약·서비스 안내에 명시했다. — 미충족: 이용 계약(14.1.1, 비기술) 확정 전

- 서명이 필요한 문서는 서명본을 스캔해 사내 문서 저장소 `CSAP/서명본/14.3.3/` 에 보관하고, md 원본에는 서명본 보관 위치를 적는다.
- 문서를 개정하면 문서 정보 표의 버전과 개정 이력을 갱신한다. 관리대장(02, 04)은 이전 버전을 3년간 보관해서 특정 시점의 현황을 확인할 수 있게 한다.
- 화면 캡처 증적에는 촬영 일시와 계정·시스템 식별 정보가 보이게 하고, 05 점검표의 보관 위치(`CSAP-인증준비/30 증적/14.3.3/`)에 모아 관리한다.
- 법령 인용은 「행정기관 및 공공기관의 클라우드컴퓨팅서비스 이용 기준 및 안전성 확보 등에 관한 고시」 제13조(행정안전부고시 제2025-79호, 2025. 12. 29. 시행) 기준이다. 관련 근거인 국가 사이버보안 기본지침 제24조의3(클라우드컴퓨팅 도입 가능 목록)은 비공개 지침이라 문서명만 표기한다. 법령·고시가 개정되면 국가법령정보센터에서 조문을 다시 확인한다.
