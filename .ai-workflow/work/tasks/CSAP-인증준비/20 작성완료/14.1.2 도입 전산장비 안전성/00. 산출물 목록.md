# 14.1.2 도입 전산장비 안전성 산출물 목록

하등급 SaaS 인증 기준 14.1.2(전자문서의 위조·변조·훼손·유출 방지 목적으로 도입하는 보안기능 보유 정보통신제품은 국가정보원장이 안전성을 확인한 제품 사용)를 충족하기 위해 준비할 산출물과 각 문서의 용도·작성 상태를 정리한다. JAS 는 물리 장비를 직접 도입하지 않는 SaaS 이므로, 대상은 당사가 운영 클러스터에 배포하는 보안기능 소프트웨어와 NCP 공공기관용 영역의 관리형 보안 서비스다. 각 구성요소의 CC 인증·보안기능 확인서 보유 여부는 2026-10-20 현재 확인 전이다.

## 2. 권장 작성 순서

1. 01 도입 전산장비 안전성 확보 절차: 도입 요건 기준과 도입·유효성 관리 절차를 정하고 정보보호 최고책임자 승인을 받는다.
2. 02 보안기능 정보통신제품 목록: 운영에 쓰는 보안기능 정보통신제품을 정보자산목록에서 발췌·식별하고 인증 현황과 함께 등재한다.
3. 03 도입 전산장비 안전성 검토서: 기존 운영 제품은 최초 1회 소급 검토하고, 이후 신규 도입 건마다 계약·이용 신청 전에 작성한다.
4. 04 안전성 인증 유효성 점검표: 운영 개시 전 최초 점검 후 연 1회 이상 운영 제품 전체의 인증 유효성을 점검하고 결과를 02 목록에 반영한다.
5. 05 증적 수집 점검표: 제품별로 인증서 사본, 검증필 목록 조회 화면, 버전 확인 화면 등을 수집·보관한다.

## 3. 심사 대비 체크리스트

2026-10-20 기준 충족 여부다.

- [ ] 보안기능을 가진 정보통신제품(정보보호시스템, 네트워크 장비·SW)을 빠짐없이 식별해 02 목록과 정보자산목록에 등재했고 두 목록이 일치한다. — 미충족: 02 목록에 식별했으나 Ingress · SealedSecrets · 로그 에이전트는 제품 미확정, 정보자산목록은 아직 없음
- [ ] 사전 인증 필수 제품군은 국가정보원장이 안전성을 확인한 제품(CC 인증 또는 보안기능 확인서 보유)을 도입했고 인증서·확인서 사본을 보관하고 있다. — 미충족: 인증 보유 여부 확인 필요(특히 SSL VPN · 웹 방화벽)
- [ ] 성능평가 대상 제품은 성능평가서를 보관하고 있다. — 미충족: 대상 여부 확인 필요
- [ ] 검증필 제품 목록에 없는 제품은 보안적합성 검증 제도로 취약점을 제거한 후에 사용하며, 세부사항은 국가정보원이 공지한 보안적합성 검증 정책을 확인했다. — 미충족: 검증필 목록 조회 전. 처리 기준은 01 절차 4항에 있음
- [ ] 도입 전에 03 검토서로 검증필 목록 등재, 인증 버전·유효기간, 인증 조건 충족을 확인하고 정보보호 최고책임자 승인을 받는 절차가 있고 이행 기록이 있다. — 절차는 있음(01 절차 5항), 이행 기록은 SSL VPN 1차 검토(대상 판단까지)만 있음
- [ ] 운영 중인 제품의 버전이 인증받은 버전과 일치하고, 미인증 버전·인증 효력을 상실한 형상 변경·유효기간 초과 상태로 운영하는 제품이 없다. — 미충족: 운영 전, 인증 확인 전
- [ ] 연 1회 이상 04 점검표로 인증 유효성을 점검하고, 유효기간 만료 예정 제품의 갱신·대체 계획을 수립했다. — 미충족: 최초 점검 전
- [ ] 패치·모듈 추가 등 형상 변경 전에 인증 효력 유지 여부를 확인하는 절차가 있고 확인 기록이 있다. — 부분 충족: 절차는 01 절차 6항에 있음, 확인 기록은 운영 후 첫 형상 변경 시 생성(05 No 6)
- [ ] IaaS/PaaS 제공자 책임 영역(물리 보안 장비, 관리형 보안 서비스)은 제공자 CSAP 인증과 계약으로 안전성을 확인했다. — 미충족: NCP 공공기관용 CSAP 인증 번호·유효기간과 관리형 서비스 인증 범위 확인 필요

## 4. 관련 산출물(다른 항목)

- 7.1.1 법적요구사항 준수: 전자정부법 제56조와 국가 사이버보안 기본지침을 법적 요구사항 목록에 등재하고 준수 여부를 함께 점검한다.
- 12.3.1 암호 정책 수립: 도입 제품의 암호 기능이 암호 정책의 알고리즘·키 길이 기준(TLS 1.2 이상, AES-256-GCM 등)을 따르도록 맞춘다.
- 14.1.3 보안관리 수준: 국가기관등 보안 요구사항에 준하는 보안 대책의 일부로 검증필 정보보호시스템 운영 현황을 활용한다.
- 14.3.1 검증필 암호화 기술 제공: SSL VPN 등 중요자료 전송·저장 제품의 검증필 암호모듈 탑재 확인과 연계한다. nginx · Node.js(OpenSSL) · PostgreSQL 의 암호 기능은 KCMVP 검증 모듈이 아니므로(공통 기준 §3.3) 14.3.1 에서 적용 방안을 결정한다. 해당 제품은 02 목록과 14.3.1 증적에 함께 나타나야 한다.
- 6.2.1 성능 및 용량 관리: NCP 공공기관용 CSAP 인증서 사본을 두 항목이 같이 쓴다.

## 5. 양식 작성 규칙

- `{{ }}`로 남긴 자리표시자는 두 종류다. 사람 이름·시행일은 비기술 양식(1.2.1 등) 확정 후 일괄 치환하고, 구성요소 버전·설치 위치·수집일은 운영 환경 구축 후 채운다. CC 인증·보안기능 확인서 관련 칸은 추측하지 않고 "확인 필요"로 둔다.
- 서명이 필요한 문서는 서명본을 스캔해 `사내 문서 저장소 CSAP/서명본/14.1.2/`에 보관하고, md 원본에는 서명본 보관 위치를 적는다.
- 문서를 개정하면 문서 정보 표의 버전과 개정 이력을 갱신하고, 목록 문서(02)는 이전 버전을 삭제하지 않고 보관한다.
- 검토서(03)는 도입 건마다 `JAS-14.1.2-03-<NN>`, 점검표(04)는 점검마다 `JAS-14.1.2-04-<YYYY>-<NN>` 번호로 새 문서를 만든다.
- 법령 인용은 전자정부법 제56조(법률 제21394호, 2026. 8. 28. 시행) 기준이다. 법령이 개정되면 국가법령정보센터에서 조문을 다시 확인한다.
- 국가 사이버보안 기본지침은 비공개 지침이라 문서명만 인용하고, 제품군별 인증 요건 등 세부사항은 국가정보원이 공지한 보안적합성 검증 정책(국가사이버안보센터 <https://www.ncsc.go.kr>, IT보안인증사무국 <https://www.itscc.kr>)으로 확인한다.
