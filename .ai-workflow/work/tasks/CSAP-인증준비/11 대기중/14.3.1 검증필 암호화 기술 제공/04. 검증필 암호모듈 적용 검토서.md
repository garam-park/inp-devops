## 1. 검토 개요

| 항목 | 내용 |
| --- | --- |
| 검토 대상 제품 | 대상 A: 관리 영역 VPN(제품 미선정). 대상 B: 이용자 ↔ 서비스 TLS 종단 구성(NCP Load Balancer TLS 또는 클러스터 Ingress 컨트롤러) |
| 검토 사유 | 신규 도입(운영 환경 구축 전 사전 검토), CSAP 심사 대비 |
| 도입 목적·용도 | A: 운영자 원격 접속 구간(운영자 PC → 배스천·NCP 콘솔·쿠버네티스 API) 암호화. B: 이용 기관 사용자 ↔ 서비스 간 중요자료(민감 레이어, 사고 기록, 인증정보) 전송 암호화 |
| 기존 운영 제품 소급 검토 여부 | 해당 없음 — 운영 중인 제품 없음 |
| 직전 검토 | 해당 없음 — 최초 검토 |

- 정기·수시 검토는 대상 제품마다 2–5항을 반복해 작성하거나, 제품별 결과를 6항 표에 요약한다. 본 검토서는 대상 A·B 를 각 표에 함께 적는다.

## 2. 검증필 암호모듈 필수 대상 판단

| 확인 항목 | 확인 결과 | 근거 |
| --- | --- | --- |
| 제품이 중요자료 전송·저장에 사용되는가 | A: 예(운영 정보·인증정보 전송). B: 예(중요자료 전송) | 공통 기준 §1.2 네트워크·영역, 12.3.1 지침 7항 |
| 지침 4항의 필수 제품 유형(VPN, 보안 USB, 호스트 자료유출 방지제품(암호화 저장 기능 보유 시), DB 암호화, DRM, SSO 등)에 해당하는가 | A: 해당(유형: VPN). B: 해당 가능(유형: 구간 암호화) — 제공자 관리형 Load Balancer 로 종단하면 제공자 관리형 기능(02 목록 4항)으로, 당사 Ingress 로 종단하면 당사 운영 구간으로 본다 | 01. 지침 4항 |
| 국가정보원 공지의 최신 필수 제품 유형 기준을 확인했는가 | {{최신 기준 조회 후 조회일 기록}} | IT보안인증사무국·국가사이버안보센터 공지, 국가 사이버보안 기본지침 제20조 |
| 판단 결과 | A: 검증필 암호모듈 필수. B: {{TLS 종단 지점 결정 후 필수 / 제공자 관리형}} | |

- 비필수로 판단한 경우 사유를 02. 정보보호제품 목록의 비고에 기록하고 이후 항은 생략할 수 있다.
