## 4. 연계 구성도

목표 구성이다. 로그 수집 노드와 기관 측 수신 구성은 운영 환경 구축·기관 협의 후 이 기관 기준으로 확정한다.

```mermaid
flowchart LR
    subgraph CSP["당사 서비스 영역(네이버클라우드 플랫폼 공공기관용 인프라 위)"]
        ING["Ingress(TLS 종단·rate limit)"]
        APP["지반침하 스마트관리 시스템 api · web"]
        SEC["보안 시스템(NCP 공공 웹 방화벽 — 도입 예정)"]
        LOG["로그·이벤트 수집(로그 저장소 — 구축 전)"]
    end
    subgraph AGENCY["이용기관 보안관제 영역"]
        SOCC["보안관제센터(자체 / 위탁 — 확인 전)"]
    end
    GSOC["정부보안관제체계"]

    ING --> LOG
    APP --> LOG
    SEC --> LOG
    LOG -->|"syslog(TLS) 또는 파일(HTTPS), 검증필 암호모듈(결정 대기)"| SOCC
    SOCC -->|"탐지정보 연계"| GSOC
```

- 실제 구성(전송 구간, IP·포트, 중계 장비)이 다르면 구성도를 이 기관 기준으로 수정한다.
- 관제용 접근 수단(ENV-03)을 제공하면 관제 요원의 접근 경로(인터넷 → 로그 저장소 조회 화면, 다중 인증)도 구성도에 표기한다.
