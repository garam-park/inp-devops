# 시스템 관리자 패스워드 관리대장

> [!warning] 취급 제한
> 본 대장은 비밀등급 문서로 분류하여 관리한다. 패스워드 원본은 본 대장에 기재하지 않고 밀봉 봉투 또는 암호화된 비밀정보 저장소에 보관하며, 본 대장은 그 목록과 소재, 열람·변경 이력을 관리한다. 패스워드 원본을 본 대장에 직접 기재하는 방식을 택한 경우 본 대장 전체를 원본과 동일하게 봉인·보관한다.

## 1. 보관 및 보호대책

| 항목 | 내용 |
| --- | --- |
| 비밀등급 분류 | 본 대장과 패스워드 기록물은 당사 문서 보안 기준의 {{비밀등급 명칭}}으로 분류한다. |
| 보관 형태 | 평시 사용하지 않는 비상용 관리자 계정은 밀봉 봉투(계정별 개별 봉인). 애플리케이션 접속 계정은 k8s Secret(SealedSecrets 봉인)으로만 보관하고 사람이 열람하지 않는다. 개인별 관리자 계정(Sub Account, GitHub)은 본인만 알고 기록하지 않는다. 당사는 비밀정보 저장소 솔루션을 쓰지 않는다 |
| 보관 장소 | {{내화금고 위치}} / 전자 보관은 운영 NKS 의 Secret(네임스페이스 RBAC 로 운영(인프라) 담당자만 조회) |
| 잠금장치·접근통제 | 내화금고 등 잠금장치로 비인가자 접근을 통제한다. 금고 열쇠·비밀번호 관리자: {{금고 관리자 성명/직위}}. 전자 보관 Secret 의 조회 권한은 아래 접근 가능자로 한정하고, 클러스터 접근에는 VPN + OTP 를 적용한다 |
| 접근 가능자 | {{접근 가능자 성명/직위}}, {{접근 가능자 성명/직위}} (2인 이내) |
| 열람 승인권자 | 정보보호 최고책임자(부재 시 {{대행 직위}}) |
| 사본 금지 | 패스워드 기록물의 복사·촬영·전자적 복제를 금지한다. |
| 봉인 관리 | 봉투에는 봉인일, 대상 계정, 봉인자 서명을 기재하고, 개봉 시 3항에 기록한 뒤 패스워드 변경 후 재봉인한다. |
