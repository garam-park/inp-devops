> [!note] 현 구현과 차이
> 2026-10-21 운영 VPC·NAT·NKS 를 1차 구축했으나 서비스 워크로드는 아직 없다. 클러스터 API(kubectl)는 기본 차단 후 사무실 고정 IP 1개만 허용하고, 인증은 IAM 액세스 항목 방식(`ncp-iam-authenticator` 로 NCP API 키 서명 토큰 사용)이며 클러스터 관리자(`NKSClusterAdminPolicy`)는 Sub Account `gov-ncloud-tofu` 하나다. NKS 감사 로그는 켰으나 저장·보존 위치는 미구성이다. 이미 동작하는 보안 도구는 CI·야간 검사(gitleaks · semgrep · npm audit · pip-audit · trivy · OWASP ZAP)와 웹 보안 응답 헤더뿐이며 1항 9·10행에 적었다. 접근통제·로그·WAF·백신은 모두 미도입이다.
