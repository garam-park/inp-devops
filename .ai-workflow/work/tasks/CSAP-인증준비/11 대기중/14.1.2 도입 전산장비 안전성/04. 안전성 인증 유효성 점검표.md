## 1. 점검 개요

| 항목 | 내용 |
| --- | --- |
| 목적 | 운영 중인 보안기능 정보통신제품이 사전 인증 효력이 없는 상태(미인증 버전, 인증 효력을 상실한 형상 변경, 인증 유효기간 초과)로 운영되지 않는지 점검하고 조치한다. |
| 점검 대상 | 양식 02. 보안기능 정보통신제품 목록 JAS-14.1.2-02 버전 {{점검 시점 02 목록 버전}}의 전체 제품(2항 6개)과 3항 관리형 보안 서비스 중 사전 인증 필요 유형(웹 방화벽, SSL VPN, Load Balancer TLS) |
| 수시 점검 사유(해당 시) | 운영 개시 전 최초 점검(심사 대비) |

## 3. 판정 기준

| 상태 | 판정 | 조치 |
| --- | --- | --- |
| 운영 버전이 인증받은 버전(인증 유지가 인정되는 범위 포함)이 아님 | 조치 필요 | 인증 유효 버전으로 전환하거나 인증 효력 유지 여부를 제조사·IT보안인증사무국에 확인 |
| 패치·모듈 추가·구성 변경으로 인증 당시 형상과 달라졌고 효력 확인이 안 됨 | 조치 필요 | 인증 효력 확인 후 효력 상실 시 재인증 버전 전환 또는 대체 도입 |
| 인증 유효기간 초과 | 조치 필요 | 갱신 인증 확인, 후속 버전 전환, 대체 제품 도입 중 택일하고 완료까지 보완 통제 적용 |
| 유효기간 만료 6개월 이내 | 유효(주의) | 갱신·대체 계획 수립 |
| 사전 인증 필수 제품군인데 인증·확인서가 없음이 새로 확인됨 | 조치 필요 | 양식 03. 검토서를 소급 작성하고 보안적합성 검증 이행 또는 대체 도입 |
| 인증 버전·형상과 일치하고 유효기간 이내 | 유효 | 유지 |
| 사전 인증 필수 제품군이 아님이 확인됨 | 해당 없음 | 판단 근거(검토서 번호)를 02 비고에 기록, 취약점 점검(야간 trivy)으로 관리 |
