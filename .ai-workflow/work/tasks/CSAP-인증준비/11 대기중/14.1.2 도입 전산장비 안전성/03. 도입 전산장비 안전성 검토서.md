> [!warning] 대기
> 이 검토서는 운영 환경 구축 시 처음 도입할 보안기능 제품 중 **해설서가 인용한 국가정보원 공지에 사전 인증 필요 제품 유형으로 명시된 가상사설망(VPN)** 을 대상으로 작성했다. 아래가 생기면 남은 칸을 채운다.
> - **NCP 공공 운영 환경 설계 확정(VPC · 관리 서브넷 · 배스천)과 SSL VPN 이용 신청 일정** → 1항 도입 대상 버전·설치 위치·도입 예정일.
> - **NCP 확인 회신(SSL VPN 의 CC 인증·보안기능 확인서·검증필 암호모듈 탑재 여부)과 검증필 제품 목록 조회** → 3·4항 결과, 6항 검토 결과, 7항 승인.
> 2–3항의 "확인 필요"는 추측으로 채우지 않았다. 다른 보안기능 제품(웹 방화벽, Ingress 컨트롤러 등)은 도입 건마다 `JAS-14.1.2-03-<NN>` 번호로 별도 검토서를 만든다.

## 2. 도입 요건 대상 판단

| 판단 항목 | 결과 | 판단 근거 |
| --- | --- | --- |
| 보안기능(식별·인증, 접근통제, 암호화, 로깅·감사 등)을 가진 정보통신제품인가 | 예 | 사용자 인증, 접근통제, 전송 구간 암호화, 접속 기록 기능을 수행한다 |
| 전자문서(공공 데이터)의 위조·변조·훼손 또는 유출 방지 목적으로 도입하는가(전자정부법 제56조제3항, 법률 제21394호, 2026. 8. 28. 시행) | 예 | 운영 DB(사고 기록·감사 기록)와 민감 레이어(관로·굴착)를 다루는 관리 영역 접근 구간을 보호한다 |
| 국가정보원이 공지한 사전 인증(CC 인증·보안기능 확인서) 필수 제품군에 해당하는가 | 예(확인 필요) | 해설서 14.1.2 가 인용한 국가정보원 공지에 가상사설망이 CC 인증 또는 보안기능 확인서 대상, 검증필 암호모듈 탑재 대상으로 나온다. 관리형 서비스 형태에도 같은 요건이 적용되는지는 국가정보원 최신 공지와 NCP 확인으로 재확인 필요. 확인일: {{국가정보원 공지 확인일}} |
| 성능평가 대상 제품군에 해당하는가 | 확인 필요 | 국가정보원·IT보안인증사무국 공지로 확인 |

- 모든 항목이 "아니오"이면 본 항목의 도입 요건 대상이 아니다. 판단 근거를 남기고 양식 02. 목록 비고에 본 검토서 번호를 적는다. 본 건은 대상이다.

## 5. 검증필 목록 미등재 시 조치 계획

검증필 제품 목록에 없는 제품은 보안적합성 검증 제도를 통해 검증 과정에서 발견된 취약점을 제거한 후에 사용할 수 있다. 세부 절차는 국가정보원이 공지한 보안적합성 검증 정책을 따른다.

| 항목 | 내용 |
| --- | --- |
| 조치 방안 | 1순위: 검증필 SSL VPN(NCP 제공 서비스가 인증 보유 시 그대로 사용, 아니면 검증필 대체 VPN 제품 도입). 2순위: 보안적합성 검증 이행. 확정: {{인증 확인 후 조치 방안}} |
| 보안적합성 검증 이행 시 계획 | 해당 시 국가정보원 공지 경로로 신청하고 취약점 조치 완료 확인 후 운영 개시. 일정: {{해당 시 일정}} |
| 검증 완료 전 임시 통제(도입이 불가피한 경우) | 운영 개시 전에는 관리 영역 원격 접근을 허용하지 않는다. 불가피하면 접근 대상을 배스천 1대로 한정, 접근 IP 허용 목록(사내 고정 IP), MFA 필수, 접속 기록 일 1회 검토를 적용하고 정보보호 최고책임자 승인을 받는다 |
