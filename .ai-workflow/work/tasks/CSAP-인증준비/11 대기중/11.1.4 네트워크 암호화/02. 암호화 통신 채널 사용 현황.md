## 1. 통신 구성 요약

지반침하 스마트관리 시스템(제주 GEO-AI 지반침하 SaaS)에서 중요정보가 이동하는 구간과 적용된 암호화 통신 채널을 표시한다(운영 목표 구조).

```mermaid
flowchart LR
    USER["이용자·이용 기관"]
    ADMIN["운영 관리자"]
    LB["Load Balancer(ALB)<br/>(TLS 종단)"]
    ING["ALB Ingress Controller<br/>(IngressClass alb)"]
    WEB["web 파드"]
    API["api 파드"]
    PIPE["pipeline 파드"]
    DB["Cloud DB for PostgreSQL"]
    OBJ["Object Storage"]
    EXT["브이월드 WMTS"]
    VPN["SSL VPN → 배스천"]
    CONSOLE["NCP 콘솔"]
    K8S["NKS API"]
    CI["GitHub Actions"]
    REG["컨테이너 레지스트리"]

    USER -- "HTTPS (TLS 1.2+)" --> LB --> ING
    ING -- "HTTP(클러스터 내부, 예외 구간)" --> WEB
    ING -- "HTTP(클러스터 내부, 예외 구간)" --> API
    API -- "TLS (sslmode=require)" --> DB
    PIPE -- "TLS (sslmode=require)" --> DB
    API -- "HTTPS" --> OBJ
    PIPE -- "HTTPS" --> OBJ
    API -- "HTTPS (TLS 1.2+)" --> EXT
    ADMIN -- "SSL VPN + SSH-2" --> VPN
    VPN -- "HTTPS" --> K8S
    ADMIN -- "HTTPS + TOTP" --> CONSOLE
    CI -- "HTTPS" --> REG
```

- TLS 종단 위치: Load Balancer(ALB) 종단. 공공 NKS(KVM)는 ALB Ingress Controller 를 기본 포함하고 IngressClass `alb` 가 기본값이다(2026-10-21 `jeju-ai-prod-nks` 확인). Ingress 를 만들면 ALB 인스턴스가 LB 서브넷(Public `jeju-ai-prod-lb-pub-sn` `10.20.11.0/24`, Private `jeju-ai-prod-lb-pri-sn` `10.20.10.0/24`)에 생기며, 리스너·인증서는 그때 확정한다. Load Balancer ↔ 파드 구간은 2항 2행·3항 1행에 기록한다.
- TLS 종단 이후 ALB → web·api 파드 구간은 같은 VPC 안(LB 서브넷 → 노드 Private 서브넷 `jeju-ai-prod-node-sn` `10.20.1.0/24`)의 전달이며 평문이다. 이 구간으로 로그인 비밀번호·세션 쿠키가 지나가므로 3항에 예외로 기록하고 보완 통제를 둔다.

## 2. 암호화 통신 채널 현황
