## 1. 점검 개요

| 항목 | 내용 |
| --- | --- |
| 목적 | 보안관제가 이루어지는 서비스 네트워크 이외의 비정상 통신경로가 발생하지 않았는지 점검하고, 격리 통제의 유효성을 확인한다. |
| 수시 점검 사유(해당 시) | 해당 없음(정기). 수시 점검은 인프라 변경, 신규 계약 인스턴스 생성, 침해 징후, 취약점 공지, 심사 대비 시 수행한다 |
| 점검 대상 | 지반침하 스마트관리 시스템 인증 범위 내 운영 자원 전체(NKS 워커 노드 {{n}}대, 컨테이너 클러스터 1식, 네트워크 구간 {{n}}개 — 운영 환경 구축 후) |
| 판정 기준선 | 양식 02. 정상 통신경로 목록 버전 {{n.n}}({{YYYY-MM-DD}} — 기준선 승인 후) |
| 점검 도구·방법 | 외부 포트 스캔(nmap, 인터넷 측 출발지), 내부 포트 스캔(클러스터 안 점검용 파드에서 nmap), NCP 콘솔·CLI 의 ACG·네트워크 ACL 내보내기, `kubectl get networkpolicy -A -o yaml`, 네임스페이스 간 연결 시험(`kubectl run` 점검 파드에서 `curl`·`nc`), 로그 저장소의 거부·변경 이벤트 조회 |
| 직전 점검 | 해당 없음 — 첫 회차 |
