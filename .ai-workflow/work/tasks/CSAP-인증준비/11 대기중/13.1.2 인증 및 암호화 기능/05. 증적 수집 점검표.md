## 3. 작성 방법

- 확인 항목의 기준을 만족하는 상태가 화면에 드러나도록 수집한다(설정값·버전·알고리즘·정책명이 보이게 캡처).
- 수집 파일명은 `13.1.2_<No>_<시스템>_<YYYYMMDD>` 형식으로 저장하고 보관 위치를 기록한다.
- 설정·기능이 변경되면 변경 후 증적을 다시 수집하고, 이전 증적은 수집일 기준으로 보관한다(양식 04의 5항과 연계). 증적은 3년 보관한다.
- 증적이 양식 03의 반영표 내용과 어긋나면 원인을 확인하고 반영표 또는 시스템 설정을 먼저 바로잡는다.
- 야간 검사 결과는 GitHub Actions 아티팩트(보존 30일)라 수집일에 내려받아 증적 폴더로 옮긴다.
