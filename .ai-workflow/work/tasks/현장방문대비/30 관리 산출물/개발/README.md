## 1. 요약

- 21종을 작성했다(Word 5, Excel 2, Markdown 14). 2종은 제외했다(3절).
- 현재 단계는 "프로토타입 분석 및 `gis-sass` 결합 방식 검토 중"이다. 결합 방식과 서비스 구성은 정해지지 않았으므로, 문서는 이를 확정된 설계처럼 쓰지 않고 "검토 중·미결정"으로 표시했다.
- 정해지지 않은 값은 지어내지 않고 `-` 또는 "미정"으로 두었다. 결정이 필요한 주요 항목은 4절이다.
- 통제항목 갭 분석(JSA-CM-CT-002)은 저장소 증거 기준의 사전 판정이다. 30개 통제항목 중 충족 0, 부분 17, 미충족 11, 해당없음 2(잠정)다.
- QA 테스트케이스(JSA-PF-TS-005)의 판정·수행일은 작업 기록과 CI 실행 기록에서 인용했다.

## 4. 공백 목록

결정이 필요한 주요 항목을 주제별로 묶었다. 세부 항목은 각 문서의 해당 절을 따른다.

- 사람·조직: 승인자와 롤백 결정자·운영 책임자는 `-` 로 두었다. 운영 체계(책임자·직무 분리·사고 대응·연락 체계)는 서비스 보안 운영체계 구성(WBS ID 34)에서 정한다(JSA-PF-OP-001 7절, JSA-PF-RL-002 5절).
- 발주처·외부: 발주처의 하등급 분류, 로그인 식별자 운영 정책, KISA 최신판(D7)과 제3자 진단 요건(D6), NCP 공공 콘솔 실측 5건(JSA-CM-CT-001), 세세부1·2 산출물 확인 질문 5건의 회신(JSA-PF-DS-002 8절).
- 기획 협의: 프로토타입 결합 방식·범위·담당(JSA-PF-DS-004 3.3절, JSA-PF-DS-003 6절), 요구사항 후보 FR-P1–P5 의 우선순위(JSA-PF-DS-001), 파일럿 목적·일정·성공 지표(JSA-CM-RL-001).
- 수치·기술 결정: 성능 목표 수치와 부하 시험 계획(WBS ID 12, AI 담당), 사내 개발·운영 배포 값, 로그 보존·서비스 간 TLS·KMS(CSAP 기준 확정 뒤) 등 JSA-PF-DS-002 8절의 열린 질문.

## 6. 작성 기준

- 기준일은 2026-10-16이다. 값과 상태는 그날의 저장소와 작업 기록을 기준으로 한다.
- 비밀값·내부 IP·개인 연락처는 넣지 않았다. 위치만 적었다.
- 승인된 설계(모듈러 모놀리식 + 선택적 분해, ADR-2026-08-26.01)와 `dev0` 구성은 사실로 적었다. 프로토타입은 데이터 표시 모듈과 데이터 표현 방식의 참조 기준 자료로 인용했고, 결합 방식은 미결정으로 표시했다.
- 각 양식의 작성 안내와 예시 행은 지우고 문서번호·파일 이름 규칙은 유지했다. 양식의 제목·표 머리글·시트 구성은 JSA-PF-DS-004 를 뺀 20종에서 유지하고 필요한 소제목·근거 자료를 덧붙였다. JSA-PF-DS-004(ADR)는 양식이 결정 1건당 문서 1개인데, ADR 25건 현황표(1절)와 결정 변경 이력(2절)을 앞에 두고 양식의 맥락·결정·검토한 대안·결과는 대표 결정 2건과 결정 대기 1건(3.1–3.3) 안에 굵은 글씨 항목으로 옮겼다.
- 판정이 필요한 곳은 증거가 있는 만큼만 판정했다. 증거가 없으면 충족으로 적지 않았다.
