## 1. 요약

- 21종을 작성했다(Word 5, Excel 2, Markdown 14). 2종은 제외했다(3절).
- 현재 단계는 "프로토타입 분석 및 `gis-sass` 결합 방식 검토 중"이다. 결합 방식과 서비스 구성은 정해지지 않았으므로, 문서는 이를 확정된 설계처럼 쓰지 않고 "검토 중·미결정"으로 표시했다.
- 근거를 찾지 못한 칸은 지어내지 않고 "확인 필요"·"미정"·"미실시"로 표시했다. 주요 목록은 4절이다.
- 통제항목 갭 분석(JSA-CM-CT-002)은 저장소 증거 기준의 사전 판정이다. 30개 통제항목 중 충족 0, 부분 17, 미충족 11, 해당없음 2(잠정)이며 T078 의 확정 판정이 아니다.
- QA 테스트케이스(JSA-PF-TS-005)의 판정·수행일은 작업 기록과 CI 실행 기록에서 인용했다. 이번 작성에서 테스트를 다시 돌리지는 않았다.
- 작성 뒤 별도 검증(7절)에서 지적된 오류·과장·범위 단서 누락을 문서에 반영했다.
- 새로 확인한 문제 12건은 5절에 있다. 가장 급한 것은 develop CI 의 `docs` 잡 실패(문서 링크 11건)다. 배포 절차(JSA-PF-RL-002)를 따르기 전에는 10·11번을 먼저 본다.
