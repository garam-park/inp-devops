# 다. 공정관리 양식

`다. 공정관리` 점검표의 문서 중 **Word · Excel · PPT · Markdown** 으로 작성하는 문서의 빈 양식이다.
코드·로그·도구 화면·도구 리포트처럼 도구가 남기는 문서는 양식이 필요 없어 만들지 않았다.

## 사용 방법

1. 양식을 복사해 저장한다. **파일명은 `{문서번호}_{문서명}` 으로 문서번호가 맨 앞(prefix)에 온다.** 버전은 파일명이 아니라 표지·제개정 이력에 적는다.
2. 문서번호(`JSA-{시스템}-{분류}-{일련번호}`)는 점검표 `다. 공정관리` 시트의 `문서번호` 열과 같고, 표지에도 이미 들어 있다. 번호 규칙은 `코드` 시트를 따른다.
3. `라. 산출물`에도 있는 문서는 같은 문서번호를 쓴다. 한 문서를 한 번만 작성해 두 점검표에 같이 낸다.
4. 회색 이탤릭 "작성 안내"와 "예)" 행은 지우고 쓴다.
