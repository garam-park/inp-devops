# 라. 산출물 양식

`라. 산출물` 점검표의 문서 중 **Word · Excel · PPT · Markdown** 으로 작성하는 문서의 빈 양식이다.
코드·로그·도구 화면(Figma, CI, Git 등)처럼 도구가 남기는 문서와 캡처·결재 증빙(PDF)은 양식이 필요 없어 만들지 않았다.

## 사용 방법

1. 양식을 복사해 저장한다. **파일명은 `{문서번호}_{문서명}` 으로 문서번호가 맨 앞(prefix)에 온다.** 버전은 파일명이 아니라 표지·제개정 이력에 적는다.
2. 문서번호(`JSA-{시스템}-{분류}-{일련번호}`)는 점검표 `라. 산출물` 시트의 `문서번호` 열과 같고, 표지에도 이미 들어 있다. 번호 규칙은 `문서 코드` 시트를 따른다.
3. 회색 이탤릭 "작성 안내"와 "예)" 행은 지우고 쓴다.

## 만들지 않은 문서

| 문서 | 이유 |
| --- | --- |
| 변경 승인 기록, 인증 증적 자료 | 결재·증빙 캡처(PDF)라 양식이 없다 |
| 설계 문서 변경 이력(Git 이력) | Git 이력에서 자동으로 나온다 |
| devcontainer·Dockerfile, API 명세(OpenAPI), ERD·DB 스키마 | 코드 |
| UI 디자인, 와이어프레임 | Figma 파일 |
| 학습 실험 기록, CI 커버리지 리포트 | 도구가 자동으로 남기는 로그 |
