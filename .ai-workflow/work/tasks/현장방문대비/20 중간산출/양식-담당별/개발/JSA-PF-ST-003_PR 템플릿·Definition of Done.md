## 1. Pull Request 템플릿

저장소의 `.github/pull_request_template.md` 에 아래 내용을 넣는다.

```markdown
## 요약
(무엇을, 왜 바꿨는가)

## 변경 내용
-

## 관련 이슈
closes #

## 테스트
- [ ] 단위 테스트 추가·수정
- [ ] 로컬에서 동작 확인

## 스크린샷(화면 변경 시)
```

## 2. Definition of Done

작업은 아래 조건을 모두 만족할 때 완료로 본다.

- [ ] 요구사항·이슈의 인수 조건을 만족한다
- [ ] 테스트가 추가되었고 CI 가 통과한다
- [ ] 코드 리뷰 승인을 받았다
- [ ] 관련 문서(API 명세·설계 문서)를 갱신했다
- [ ] 보안·성능 영향을 확인했다
- [ ] 체인지로그에 반영했다
