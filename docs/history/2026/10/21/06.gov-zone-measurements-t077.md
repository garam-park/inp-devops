- 날짜: 2026-10-21
- 요청: gov-ncloud 다음 할 일 3단계(공공존 기능 확인)를 한 번에 처리하고, 결과를 gis-sass 와 gov-ncloud 두 곳에 남긴다.
- 이전 기록: [04.bump-gov-ncloud-submodule.md](04.bump-gov-ncloud-submodule.md)

## 배경

gis-sass ADR 2026-09-26.02 D4(운영 타깃 NCP 공공기관용 NKS + Cloud DB for PostgreSQL)는 공공 콘솔 실측 5건을 승인 조건으로 두고, 결과를 `planning/tasks/T077.md` 진행 현황에 적으라고 했다.
같은 사실을 gov-ncloud 가 인프라를 만들 때 쓴다. 한 저장소만 보는 사람도 필요한 내용을 얻도록 두 곳에 나눠 적었다(사용자 결정).

## 확인 방법

- 공공존 API(읽기만, `gov` 프로필): `vserver getZoneList`, `vpostgresql getCloudPostgresqlImageProductList`, NKS API `option/version`·`option/server-image`·`clusters`(HMAC 서명 스크립트는 세션 scratchpad, 저장소에 넣지 않음).
- 공공 가이드(guide-gov.ncloud-docs.com): NKS 사용 준비·시작, ALB Ingress Controller 설정, Cloud DB for PostgreSQL Extension 관리, Container Registry 개요·사용 준비.
- 공지 550, NKS 공지 563, FAQ 4586·4587: 본문을 스크립트로 불러오는 페이지라 자동으로 읽지 못했다. 사용자가 브라우저에서 저장한 HTML(`.temp/`, git 추적 안 함)에서 본문을 뽑았다. Chrome 확장은 연결되어 있지 않았다.
