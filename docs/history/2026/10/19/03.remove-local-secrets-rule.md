# 우산 AGENTS.md 에서 `~/ops/inp/local/` 비밀값 규칙 삭제

- 날짜: 2026-10-19
- 요청: 비밀값을 `~/ops/inp/local/` 에 두는 규칙은 이제 맞지 않으니 지운다. 새 위치는 나중에 정한다.
- 이전 기록: [../14/01.workspace-setup.md](../14/01.workspace-setup.md)

## 배경

dev0 의 GHCR pull 토큰을 어디에 둘지 이야기하다가 나왔다. 규칙은 "비밀값, kubeconfig, 백업은 `~/ops/inp/local/` 에 둔다"였지만 실제로는 지켜지지 않았다.

- `~/ops/inp/local/` 에는 옛 클러스터 `k8s-1` 폴더만 있다. `dev0` 폴더는 없다.
- dev0 의 비밀값(`talos/_out/`, `tofu/secrets.auto.tfvars`)은 dev0 저장소 안에 두고 `.gitignore` 로 뺀다. 10-14 기록에도 도구가 저장소 안 경로를 기대해서 그렇게 뒀다고 적혀 있다.

## 변경 내용

- `AGENTS.md` 구조 절: `- 비밀값, kubeconfig, 백업처럼 git 에 넣지 않는 파일은 \`~/ops/inp/local/\`에 둔다.` 줄 → 삭제

## 결정과 이유

규칙만 먼저 지우고 새 위치는 정하지 않았다(사용자 결정). 검토한 후보는 세 가지다. (A) 저장소 안의 gitignore 폴더, (B) macOS 키체인, (C) SOPS+age 로 암호화해 git 에 넣기.

## 검증

`git diff AGENTS.md` 로 그 한 줄만 빠진 것을 확인했다.

## 되돌리는 방법

이 커밋을 되돌리거나, 구조 절 끝에 지운 줄을 다시 넣는다.

## 남은 일

- 비밀값 위치를 정한다.
- dev0 저장소의 README 두 곳은 아직 `~/ops/inp/local/dev0/` 를 가리킨다. 위치를 정한 뒤 dev0 저장소에서 고친다. 대상은 `apps/official-website/README.md`, `apps/jeju-subsidence-ai/README.md` 와 할 일 W65 의 설명이다.
