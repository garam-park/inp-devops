# jeju-ai-saas-be, jeju-ai-saas-fe 를 projects/ 서브모듈로 등록

- 날짜: 2026-10-19
- 요청: `projects/jeju-ai-saas-be`, `projects/jeju-ai-saas-fe` 를 서브모듈로 한다.
- 이전 기록: [Jeju-subsidence FE·BE 분리 설계](../../17/01.jeju-subsidence-fe-be-split-design.md)

## 배경

- 두 폴더는 ws 에서 추적되지 않는(`??`) 독립 git 저장소였다. 각각 `develop` 브랜치에 `first commit` 하나가 있고,
  `origin` 은 `git@github.com:innopam/jeju-ai-saas-be.git`, `git@github.com:innopam/jeju-ai-saas-fe.git` 다.
- 작업 시점에 두 원격 모두 `git ls-remote origin` 결과가 비어 있었다. 즉 아직 push 되지 않았다.

## 변경 내용

- `.gitmodules`: 두 항목 추가. 둘 다 `branch = develop`
  - `projects/jeju-ai-saas-be` → `git@github.com:innopam/jeju-ai-saas-be.git`
  - `projects/jeju-ai-saas-fe` → `git@github.com:innopam/jeju-ai-saas-fe.git`
- `projects/jeju-ai-saas-be`: 고정 커밋 `a6650ad`(develop, first commit)
- `projects/jeju-ai-saas-fe`: 고정 커밋 `b93ac7c`(develop, first commit)
- 두 서브모듈의 `.git` 디렉터리를 `git submodule absorbgitdirs` 로 `.git/modules/projects/jeju-ai-saas-{be,fe}` 로 옮겼다.
  서브모듈 안에는 `.git` 파일(gitdir 포인터)만 남는다. 다른 서브모듈과 같은 구조다.
- `README.md`: 서브모듈 목록에 두 줄 추가
- 커밋하지 않았다. 인덱스에만 올라가 있다.

## 결정과 이유

- 기존 저장소를 그대로 등록했다(`git submodule add -b develop <url> <path>` 가 "Adding existing repo" 로 처리). 다시 clone 할 원격 내용이 없기 때문이다.
- 따라가는 브랜치는 두 저장소의 현재 브랜치인 `develop` 으로 했다.
- 서브모듈 push 는 요청 범위 밖이라 하지 않았다.

## 검증

- `git submodule status` 에 `a6650ad projects/jeju-ai-saas-be (heads/develop)`, `b93ac7c projects/jeju-ai-saas-fe (heads/develop)`
- `git status -s` 에 `A projects/jeju-ai-saas-be`, `A projects/jeju-ai-saas-fe`, `M .gitmodules`
- 두 서브모듈의 `.env` 는 각 저장소 `.gitignore` 에 걸려 있다(`git check-ignore .env`). ws 에는 gitlink 만 올라간다.

## 되돌리는 방법

- 커밋 전이다. 작업 폴더는 지우지 않고 등록만 푼다.
  `git rm --cached projects/jeju-ai-saas-be projects/jeju-ai-saas-fe` 후 `git restore --staged --worktree .gitmodules README.md`.
  `.git` 을 서브모듈 폴더 안으로 되돌리려면 `projects/jeju-ai-saas-{be,fe}/.git` 파일을 지우고
  `.git/modules/projects/jeju-ai-saas-{be,fe}` 를 그 자리로 `mv` 한 뒤 그 안 `config` 의 `core.worktree` 줄을 지운다.

## 남은 일

- 두 서브모듈을 원격에 push. 그 전에는 ws 를 push 하지 않는다(다른 곳에서 받으면 없는 커밋을 가리킨다).
- ws 커밋과 push
