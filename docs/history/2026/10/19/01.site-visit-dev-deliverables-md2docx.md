# 현장방문 대비 개발 산출물 md 를 docx 로 변환

- 날짜: 2026-10-19
- 요청: `.ai-workflow/work/tasks/현장방문대비/30 관리 산출물/개발`의 md 파일을 docx 로 바꿔 같은 폴더의 `md2docx/`에 넣기.
- 이전 기록: [01.site-visit-dev-deliverables-fact-check.md](../17/01.site-visit-dev-deliverables-fact-check.md)

## 배경

현장방문 제출용 개발 산출물 중 md 로 작성된 문서를 docx 로도 갖춰 두기 위함.

## 변경 내용

- `.ai-workflow/work/tasks/현장방문대비/30 관리 산출물/개발/md2docx/`: 빈 폴더 → docx 15개 추가 (README.md 포함, 폴더의 md 15개 전부, 파일명은 확장자만 바꿈)
- 원본 md 와 기존 docx·xlsx 는 건드리지 않음.

## 결정과 이유

- `pandoc -f gfm -t docx`로 변환. 스타일은 pandoc 기본값(별도 reference-doc 없음).
- mermaid 코드 블록 6개(DS-002 2개, DS-003 3개, OP-001 1개)는 코드로 남으면 읽을 수 없어 Lua 필터로 `@mermaid-js/mermaid-cli@11.4.2`(시스템 Chrome 사용, 배율 3, 흰 배경) PNG 로 렌더링해 넣음. 필터와 중간 파일은 세션 scratchpad 에만 있고 저장소에는 없음.

## 검증

- 15개 모두 오류 없이 생성됨.
- 그림 포함 개수 확인: DS-003 3개, DS-002 2개, OP-001 1개.
- DS-003 첫 다이어그램 PNG 를 열어 한글 라벨이 정상 렌더링됨을 확인.
- `JSA-PF-ST-001_코딩 컨벤션.docx`를 텍스트로 되읽어 표가 유지됨을 확인.
- Word 에서 직접 열어 레이아웃을 본 것은 아님(미검증).

## 추가 변경: 북마크 제거

- 요청: 생성된 docx 의 북마크를 없애기.
- 원인: pandoc 이 gfm 제목마다 자동 ID 를 만들고, docx 에서 이를 북마크(`w:bookmarkStart`)로 넣음. 파일당 6–14개.
- 변경: 입력 형식을 `-f gfm` → `-f gfm-gfm_auto_identifiers`로 바꿔 15개를 다시 변환. (`-auto_identifiers`는 gfm 에서 지원하지 않아 실패함.)
- 영향: md 에 문서 내부 앵커 링크(`](#...)`)가 없어 깨지는 링크는 없음.
- 원래 폴더의 docx 5개(PRD 등)는 확인 결과 북마크가 0개라 건드리지 않음.
- 검증: 15개 모두 `w:bookmarkStart` 0개, 그림 개수는 이전과 같음(DS-002 2, DS-003 3, OP-001 1).

## 되돌리는 방법

`md2docx/` 안의 docx 15개를 삭제.

## 남은 일

- md 를 고치면 다시 변환해야 함.
- 기존 docx 들과 서식(글꼴·표 스타일)을 맞추려면 그중 하나를 `--reference-doc`으로 지정해 재변환.
