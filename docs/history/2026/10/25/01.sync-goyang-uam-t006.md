# 고양 UAM 저장소의 T006 완료 커밋을 우산 저장소 포인터에 반영

- 날짜: 2026-10-25
- 요청: T006(simulation2 경고 카드 닫기 버튼)의 PR 병합과 마무리까지 진행한 뒤, 우산 저장소가 새 프로젝트 커밋을 가리키게 한다.
- 이전 기록: [T005 완료 커밋 포인터 반영](07.sync-goyang-uam-t005.md)

## 배경

고양 UAM 프로젝트 저장소에서 T006(simulation2 "운항 실행" 패널의 경고 카드 닫기 버튼)을 마쳤다. T005 에서 만든 경고 카드에 닫기가 없어서, 사용자가 브라우저 코멘트로 "닫기가 없어. 닫을 수 있어야하는데" 라고 지적한 것을 반영한 작업이다.

프론트 PR #238 을 `develop` 에 병합하고, 목업 반영 · 기록 · 아카이브 커밋을 만들어 `origin/develop` 에 push 했다(`4c5e1fd` → `0497ba7`).

우산 저장소의 `projects/goyang-uam` gitlink 는 T005 완료 커밋 시점인 `3b6b0e1` 에 고정돼 있었다.

## 변경 내용

- `projects/goyang-uam`: `3b6b0e1` → `0497ba7` 로 gitlink를 갱신한다.
- 우산 저장소의 현재 사용자 변경인 `AGENTS.md`, `ops/dev0`, `ops/gov-ncloud`, 기존 감리 기록(10-24/01·03)과 `ops/inbox/` 는 이 작업에 포함하지 않는다.

## 결정과 이유

- 프로젝트 저장소 커밋이 원격에 먼저 올라간 것을 확인한 뒤 우산 저장소 포인터를 갱신한다. clone 시 존재하지 않는 커밋을 가리키지 않게 하기 위해서다.
- 기록 파일 순번은 이 저장소 `docs/history/2026/10/25/` 폴더의 마지막 번호에 1을 더해 `01` 을 쓴다. 프로젝트 저장소 쪽 기록은 별도 폴더이므로 그쪽 `docs/history/2026/10/25/01` 과 같은 날짜·번호를 쓴다.
- 앱 저장소 변경은 프론트 하나뿐이다(병합 커밋 `816ecfe`). 백엔드 저장소는 이 작업에서 건드리지 않았다.
