# 고양 UAM 저장소의 T007 완료 커밋을 우산 저장소 포인터에 반영

- 날짜: 2026-10-25
- 요청: T007(simulation2 소음 설정 가독성 정리)의 배치 리뷰와 정렬 수정까지 마치고 PR 병합 · 기록 · 아카이브까지 진행한 뒤, 우산 저장소가 새 프로젝트 커밋을 가리키게 한다.
- 이전 기록: [T006 완료 커밋 포인터 반영](01.sync-goyang-uam-t006.md)

## 배경

고양 UAM 프로젝트 저장소에서 T007(simulation2 "운항 실행" 패널의 소음 설정 가독성 정리)을 마쳤다. T005 · T006 으로 정리한 경고 영역 다음으로 같은 패널의 소음 설정 영역을 손댔다.

이번 라운드에서는 배치를 두 가지 만들어 비교했고, 사용자가 **좌우(라벨 왼쪽 · 내용 오른쪽)** 안을 택했다. 이어서 "좌측 시작점 라인이 안 맞는 거 같아" 라는 지적을 받아 AntD 체크박스가 형제에게 붙이는 8px 여백을 무력화했다.

프론트 PR #239 를 `develop` 에 병합하고, 목업 반영 · 기록 · 아카이브 커밋을 만들어 `origin/develop` 에 push 했다(`0497ba7` → `801ebed`).

우산 저장소의 `projects/goyang-uam` gitlink 는 T006 완료 커밋 시점인 `0497ba7` 에 고정돼 있었다.

## 변경 내용

- `projects/goyang-uam`: `0497ba7` → `801ebed` 로 gitlink를 갱신한다.
- 우산 저장소의 현재 사용자 변경인 `AGENTS.md`, `ops/dev0`, `ops/gov-ncloud`, 기존 감리 기록(10-24/01·03, 10-25/02·03)과 `ops/inbox/` 는 이 작업에 포함하지 않는다.

## 결정과 이유

- 프로젝트 저장소 커밋이 원격에 먼저 올라간 것을 확인한 뒤 우산 저장소 포인터를 갱신한다. clone 시 존재하지 않는 커밋을 가리키지 않게 하기 위해서다.
- 기록 파일 순번은 이 저장소 `docs/history/2026/10/25/` 폴더의 마지막 번호에 1을 더해 `04` 를 쓴다. 같은 날 폴더에 `02` · `03` 이 이미 있으므로 겹치지 않게 `04` 다. 프로젝트 저장소 쪽 기록은 별도 폴더라 그쪽 `docs/history/2026/10/25/02` 를 썼다.
- 앱 저장소 변경은 프론트 하나뿐이다(병합 커밋 `4f8794b`). 백엔드 저장소는 이 작업에서 건드리지 않았다.
