# 박가람의 10월 업무 시트에 네 프로젝트 실적을 통합했다

- 날짜: 2026-10-30
- 요청: projects 아래 다른 프로젝트의 10월 커밋도 확인한 결과를 구글 시트에 작성
- 이전 기록: [포트홀 실적 반영](../../../../../projects/porthole/docs/history/2026/10/30/26.october-work-summary-sheet-entry.md)

## 배경

최초 시트에는 포트홀 실적만 작성됐다. 사용자가 projects 전체의 같은 이메일 커밋 조사를 요청했고, 제주 지반침하 AI·고양 UAM·회사 홈페이지 실적을 추가 확인한 뒤 시트 작성을 지시했다.

## 변경 내용

- [월간 업무 시트](https://docs.google.com/spreadsheets/d/1GVi8pNKbGmfmtNRNMYH4bTtvs4gHpgDd/edit?gid=2129655161#gid=2129655161)의 팀별 월간 주요 업무, 박가람 Y124:Y131 병합 셀: 포트홀 7개 세부 항목 → 네 프로젝트의 수행 내용을 묶은 통합 문안.
- 해당 셀만 수정했다. 구분 프로젝트·비율·팀장 작성란·인원 투입 시트는 변경하지 않았다.

- 개발서버 접속 포트·외부 연계 확인 항목 정리

[제주 지반침하 AI]
- 로그인·계정·조직/워크스페이스 권한 관리 구현
- 데이터 업로드·버전 관리·PostGIS 적재 및 지도 조회 구현

- 충돌·회랑·기상·소음·관제권·인구 구역·주기장 판정 구현
- 버티포트·노선·구역 지도 편집 및 화면·저장 오류 개선

## 결정과 이유

- garam-park@naver.com의 한국시간2026년10월 작성일을 기준으로 로컬 브랜치·원격 추적·태그에서 조사했다. fetch·stash·미커밋 변경은 포함하지 않았다.
- 12개 저장소789개 고유 커밋: 포트홀119, 제주 AI322, 고양 UAM339(별도 배포 스냅샷1건 포함), 회사 홈페이지9. 병합·버전·문서 커밋을 업무별로 중복 집계하지 않고 구현 파일과 기존 작업 기록을 대조했다.
- 제주 AI는 BE 48347b647·05423eff4·3238f6ea8·0d756f990, FE cecab9c6f 등을 대조했다. 고양은 FE df65eafab·d4128613d·cfc0dbf64, BE ecb86149f·b300f8253, DB b13e00092 등을 확인했다. 홈페이지는 b1e2f56bd·7338b6312·4cfce1049를 확인했다.
- 구현 실적을 운영 배포·실제 SSO 연동·CSAP 인증 완료로 확대하지 않았다. 투입시간·비율도 커밋으로 추정하지 않았다.
- 이전 포트홀 상세 내용은 기존 기록에 보존하고 통합 칸에서는 문서 종류·데이터 정책·검토/생성·접속 준비를 요약했다.

## 검증

- 브라우저에서 입력 문안과 드라이브 저장됨을 확인했다.
- 수정 직전/직후 XLSX 읽기 사본의 모든 셀 값·수식을 비교해 sheet1 Y124만 변경됐음을 확인했다.
- 열 구성·병합 범위·행 높이는 동일하며, 네 프로젝트 제목과 전체525자를 대조했다.
- 화면을 위·아래로 이동해 포트홀·제주 AI·고양 UAM·홈페이지가 순서대로 표시되는 것을 확인했다. 글꼴 축소·열/행 크기 변경은 하지 않았다.
- 제품 코드·원자료·서브모듈 포인터·권한은 수정하지 않았다. 이번 작업에서 제품 테스트를 다시 실행하지 않았다.

## 되돌리는 방법

Y124의 문안을 앞선 포트홀 반영 기록의 문안으로 되돌린다. 전체 파일 버전 복원으로 다른 사람 변경까지 되돌리지 않는다.
