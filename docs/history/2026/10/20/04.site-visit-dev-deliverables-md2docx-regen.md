`md2docx/` 의 docx 는 10/19 13:33–13:47 에 만든 것인데, 그 뒤 같은 폴더의 md 가 바뀌었다. 마지막 변환 커밋(`45ab4b4`) 기준으로 md 14종이 달라졌다(ST-005 는 SaaS 서버·화면 절 추가로 130줄, 나머지 13종은 4–6줄씩. 커밋 `042678c` 의 승인·작성자 정보 변경과 미커밋 변경 포함). `README.md` 는 바뀌지 않았다.

## 변경 내용

- `md2docx/` 의 docx 14개(CM-RL-002, CF-007, DS-002, DS-003, DS-004, IM-002, OP-001, RL-002, RL-003, RL-004, ST-001, ST-002, ST-003, ST-005): 10/19 변환본 → 현재 md 로 다시 변환한 것으로 교체.
- `md2docx/README.docx`: 원본 `README.md` 가 바뀌지 않아 그대로 둠(10/19/04 기록과 같은 기준).
- 원본 md, 폴더의 다른 docx·xlsx 는 건드리지 않음.

## 결정과 이유

- 변환 방식은 10/19/01 기록과 같다. `pandoc 3.9.0.2`, `pandoc -f gfm-gfm_auto_identifiers -t docx --lua-filter mermaid.lua`. 북마크를 만들지 않도록 `gfm_auto_identifiers` 를 끈다.
- mermaid 블록 6개(DS-002 2, DS-003 3, OP-001 1)는 Lua 필터가 `npx -y -p @mermaid-js/mermaid-cli@11.4.2 mmdc -b white -s 3` 로 PNG 로 렌더링해 넣는다. puppeteer 설정은 `executablePath` 를 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome` 으로 지정. 필터·puppeteer 설정·중간 PNG 는 세션 스크래치패드에만 있고 저장소에는 없다.
- 스크래치패드 `out/` 에 먼저 만들어 검증한 뒤 `md2docx/` 로 복사했다.
- 스타일은 pandoc 기본값(`--reference-doc` 없음). 기존 docx 와 서식을 맞추는 일은 이번 범위가 아니다.
