# jeju-ai-saas-be · fe 서브모듈을 projects/jeju-ai/apps/ 아래로 옮김

- 날짜: 2026-10-20
- 요청: `projects/jeju-ai/jeju-ai-saas-be`, `projects/jeju-ai/jeju-ai-saas-fe` 두 서브모듈을 `projects/jeju-ai/apps` 로 옮긴다.
- 이전 기록: [../19/06.move-jeju-ai-saas-be-under-jeju-ai.md](../19/06.move-jeju-ai-saas-be-under-jeju-ai.md), [../19/07.move-jeju-ai-saas-fe-under-jeju-ai.md](../19/07.move-jeju-ai-saas-fe-under-jeju-ai.md)

## 배경

`projects/jeju-ai/` 아래에 `apps/`(빈 폴더), `docs/`, `tasks/` 를 두는 구조로 정리하면서, 앱 저장소 두 개를 `apps/` 로 모은다.

## 변경 내용

- 서브모듈 작업 트리 (`git mv`):
  - `projects/jeju-ai/jeju-ai-saas-be` → `projects/jeju-ai/apps/jeju-ai-saas-be`
  - `projects/jeju-ai/jeju-ai-saas-fe` → `projects/jeju-ai/apps/jeju-ai-saas-fe`
- `.gitmodules` 의 두 항목 `path`: 위와 같이 `apps/` 를 넣은 경로로 바뀜
- 각 서브모듈 `.git` 파일 `gitdir`: `../../../.git/modules/projects/jeju-ai-saas-{be,fe}` → `../../../../.git/modules/projects/jeju-ai-saas-{be,fe}`, `core.worktree` 는 `../../../../projects/jeju-ai/apps/jeju-ai-saas-{be,fe}` (`git mv` 가 바꿨다)
- `ops/dev0` 고정 커밋: `2142fa0` → dev0 README 경로 수정 커밋
- `README.md` 서브모듈 목록 9–10줄: `projects/jeju-ai/jeju-ai-saas-{be,fe}` → `projects/jeju-ai/apps/jeju-ai-saas-{be,fe}`

## 결정과 이유

- 06 · 07 과 같이 서브모듈 이름(`submodule.projects/jeju-ai-saas-{be,fe}`)과 `.git/modules/projects/jeju-ai-saas-{be,fe}` 는 그대로 둔다. 이름을 바꾸면 다른 클론에서 모듈 디렉터리를 다시 받아야 한다.
- 고정 커밋은 바꾸지 않았다 (be `2e81599`, fe `8505ed2`).
- `ops/dev0/apps/jeju-ai-saas/README.md` 72줄의 `cd` 경로도 새 위치로 고쳤다. dev0 저장소에서 커밋하고(dev0 기록 `docs/history/2026/10/20/03.jeju-ai-saas-readme-be-path.md`), ws 의 `ops/dev0` 고정 커밋을 갱신했다.

## 검증

- `git submodule status` 에 `projects/jeju-ai/apps/jeju-ai-saas-be (heads/develop)`, `projects/jeju-ai/apps/jeju-ai-saas-fe (heads/develop)` 로 나타난다
- 새 경로에서 두 서브모듈 모두 `git status -sb` 가 `develop...origin/develop`, 변경 없음
- 빌드·테스트는 경로 이동만이라 돌리지 않았다

## 되돌리는 방법

`git mv projects/jeju-ai/apps/jeju-ai-saas-be projects/jeju-ai/jeju-ai-saas-be` (fe 도 같게) 후 `README.md` 두 줄을 원래 경로로 고친다.
