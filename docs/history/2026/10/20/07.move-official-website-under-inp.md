# official-website 서브모듈을 projects/inp/ 아래로 옮김

- 날짜: 2026-10-20
- 요청: `projects/official-website` 를 옮긴다. 요청 문장의 도착 경로가 출발 경로와 같아(오타) 물어본 뒤
  `projects/inp/official-website` 로 정했다.
- 이전 기록: [06.move-gis-sass-and-jeju-subsidence-ai-under-jeju-ai-repos.md](06.move-gis-sass-and-jeju-subsidence-ai-under-jeju-ai-repos.md)

## 배경

06 에서 제주 관련 저장소를 `projects/jeju-ai/` 아래로 모았다. 회사 홈페이지 저장소도 같은 식으로 제품(고객) 단위 폴더
`projects/inp/` 아래에 둔다. `projects/inp/` 는 `projects/jeju-ai/repos/` 와 같은 시각에 빈 폴더로 만들어져 있었다.
이로써 `projects/` 바로 아래에는 `inp/`, `jeju-ai/` 두 폴더만 남는다.

## 변경 내용

- 서브모듈 작업 트리 (`git mv`): `projects/official-website` → `projects/inp/official-website`
- `.gitmodules` 의 `[submodule "projects/official-website"]` `path`: `projects/official-website` → `projects/inp/official-website`
- 서브모듈 `.git` 파일 `gitdir`: `../../.git/modules/projects/official-website` → `../../../.git/modules/projects/official-website`,
  `.git/modules/projects/official-website/config` 의 `core.worktree`: `../../../../projects/official-website`
  → `../../../../projects/inp/official-website` (`git mv` 가 바꿨다)
- `README.md` 서브모듈 목록 줄: `projects/official-website` → `projects/inp/official-website`

## 결정과 이유

- 도착 경로 후보로 `projects/inp/official-website` 와 `projects/inp/repos/official-website` 를 제시했고, 사용자가 앞쪽을 골랐다.
- 06 과 같이 서브모듈 이름(`submodule.projects/official-website`)과 `.git/modules/projects/official-website` 는 그대로 둔다.
- `docs/history/` 의 옛 경로 언급은 그때의 기록이라 고치지 않았다. 그 밖에 옛 경로를 쓰는 추적 파일은 `README.md` 뿐이었다
  (`git grep` 으로 확인).
- 커밋하지 않았다. 사용자가 요청하지 않았다.

## 검증

- `git status -s`: `R projects/official-website -> projects/inp/official-website` (스테이징됨), `M .gitmodules`
- `git submodule status`: `220350b projects/inp/official-website (1.0.2)`. 고정 커밋은 옮기기 전과 같다.
- 새 경로에서 `git -C projects/inp/official-website status -sb`: `main...origin/main`, 변경 없음.
- `projects/` 바로 아래에 `official-website` 폴더가 남아 있지 않다.
- `README.md` 와 이 기록이 markdownlint 를 통과했다.

## 되돌리는 방법

`git mv projects/inp/official-website projects/official-website` 후 `README.md` 줄을 원래 경로로 고친다.
(`.gitmodules` 는 `git mv` 가 다시 고친다.)

- 다른 클론에서 받을 때: `git pull` 뒤 `git submodule update --init projects/inp/official-website`. 옛 경로 폴더가 남아 있으면 손으로 지운다.
