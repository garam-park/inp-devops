## 배경

CSAP 하등급 SaaS 인증을 준비한다. 양식 188건 중 개발·운영 지식이 필요한 141건을 채운다.
대상 시스템은 jeju-ai-saas-be/fe 다. 이 둘은 프로토타입 jeju-subsidence-ai 를 나눈 것이고, 앞으로 gis-sass 설계를 따른다.
운영 타깃은 NCP 공공기관용(gis-sass ADR 2026-09-26.02 결정 D4)이고 아직 구축 전이다. dev0 는 배포처가 아니다.

## 결정과 이유

- 정책·지침·절차·기준은 gis-sass 설계와 제품 설계안을 목표 상태로 삼아 끝까지 썼다. 현황·대장·결과서처럼 실제 상태를 적는 문서는 지금 채울 수 있는 데까지 채우고 대기로 보냈다. 심사는 "문서대로 하는가"를 보므로 미구현을 구현된 것처럼 쓰지 않았다.
- 사람 이름·승인일·비상연락망처럼 비기술 양식(1.2.1·2.1.2·5.1.1 03 등)에서 정해지는 값은 `{{...}}` 로 두었다. 이 값만 남은 문서는 작성완료로 판정했다.
- 회사가 정하는 내부 기준값(패스워드 10자·5회 잠금, 로그 보존 3년, RPO 24h·RTO 4h 등)은 해설서 예시와 gis-sass 값을 기준으로 임시로 정했다. 사용자 확인 전이다.
- 141건을 묶음 9개로 나눠 서브에이전트가 병렬로 썼다. 첫 시도(묶음 5개)는 사용자가 중단했고, 다시 9개로 띄웠다.

## 검증

- 상태 폴더 파일 수: 작성완료 70, 대기중 71, 작성중 0. 합계 141 이다.
- 작성완료 문서에 `{{대기` 자리표시자 0, 범위 표기 `~` 0.
- 상대 링크 414개 검사, 깨짐 0.
- 내용의 정확성은 묶음별 에이전트의 자체 검증에 기댔다. 사람이 141건 본문을 검토하지 않았다. **미검증**이다.
- GitHub 조직 설정은 에이전트가 `gh api` 로 읽기만 해서 확인했다. 2단계 인증 필수 설정이 꺼져 있고, 구성원 17명 중 7명이 미설정이다.
