# 고양 UAM 저장소의 T001 완료 커밋을 우산 저장소 포인터에 반영

- 날짜: 2026-10-24
- 요청: T001(기체 상태 코드값 후속)의 PR 병합과 마무리까지 진행한 뒤, 우산 저장소가 새 프로젝트 커밋을 가리키게 한다.
- 이전 기록: [점 관리 CRUD 병합 커밋 포인터 반영](05.sync-goyang-uam-point-crud.md)

## 배경

고양 UAM 프로젝트 저장소에서 T001(`aircraft.oprt_stts_cd` 코드값 변경 후속)의 코드 변경과 기록을 마치고 PR #115(백엔드)·#236(프론트)을 `develop` 에 병합했다. 이어서 API 가이드 커밋, 서브모듈 포인터 갱신 커밋, T001 아카이브 커밋까지 만들어 `origin/develop` 에 push 했다(`01b8a397 → a1a5c045`).

우산 저장소의 `projects/goyang-uam` gitlink 는 이전 작업(T004 완료 커밋) 시점인 `01b8a397` 에 고정돼 있었다.

## 변경 내용

- `projects/goyang-uam`: `01b8a397` → `a1a5c045`로 gitlink를 갱신한다.
- 우산 저장소의 현재 사용자 변경인 `AGENTS.md`, `ops/dev0`, `ops/gov-ncloud`, 기존 감리 기록(10-24/01·03)과 `ops/inbox/` 는 이 작업에 포함하지 않는다.

## 결정과 이유

- 프로젝트 저장소 커밋이 원격에 먼저 올라간 것을 확인한 뒤 우산 저장소 포인터를 갱신한다. clone 시 존재하지 않는 커밋을 가리키지 않게 하기 위해서다.
- 기록 파일 순번은 이 저장소 `docs/history/2026/10/24/` 폴더의 마지막 번호(`05`)에 1을 더해 `06` 을 쓴다. 프로젝트 저장소 쪽 기록은 별도 폴더이므로 그쪽 마지막 번호(`04`)에 1을 더한 `05` 를 쓴다.
- 앱 저장소 두 개의 병합 커밋(백엔드 `c45ad9c`, 프론트 `1172364`)은 GitHub 에 이미 올라가 있고, 프로젝트 저장소의 서브모듈 포인터도 그 커밋을 가리킨다.
