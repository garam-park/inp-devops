# 고양 UAM 저장소의 점 관리 CRUD 병합 커밋을 우산 저장소 포인터에 반영

- 날짜: 2026-10-24
- 요청: TSK-4235 점 관리 CRUD 병합까지 마무리하면서 고양 UAM 프로젝트 저장소의 새 커밋을 우산 저장소에서 가리키게 한다.
- 이전 기록: [T004 완료 커밋 포인터 갱신](04.sync-goyang-uam-pointer.md)

## 배경

고양 UAM 프로젝트 저장소에서 simulation2 점 관리 CRUD 작업의 병합 반영 커밋 `01b8a397`(`apps/gygo-svc3d-front-uamms` 서브모듈 포인터 갱신 + 작업 기록)을 만들어 `origin/develop` 에 push 했다(`f0fffed4 → 01b8a397`). 우산 저장소의 `projects/goyang-uam` gitlink 는 T004 완료 커밋 `f0fffed4` 에 고정돼 있었다.

## 변경 내용

- `projects/goyang-uam`: `f0fffed4` → `01b8a397`로 gitlink를 갱신한다.
- 우산 저장소의 현재 사용자 변경인 `AGENTS.md`, `ops/gov-ncloud`, 기존 감리 기록(10-24/01·03)과 `ops/inbox/` 는 이 작업에 포함하지 않는다.

## 결정과 이유

- 프로젝트 저장소 커밋이 원격에 먼저 올라간 것을 확인한 뒤 우산 저장소 포인터를 갱신한다. clone 시 존재하지 않는 커밋을 가리키지 않게 하기 위해서다.
- 앱 저장소 PR #234(병합 커밋 `7b7e786`)와 병합 기록 PR #235(병합 커밋 `28840b5`)는 GitHub 에 이미 병합됐고, 프로젝트 저장소의 서브모듈 포인터도 `28840b5` 를 가리킨다.

## 검증

- 고양 UAM 프로젝트 저장소 push 성공: `f0fffed4..01b8a397`.
- 앱 저장소 PR #234 `Merged`(`7b7e786`, 12개 파일 · 1,646 additions), PR #235 `Merged`(`28840b5`, 1개 파일 · 3 additions · 1 deletion) 를 브라우저로 확인했다.
- 앱 저장소 `npm test -- src/pages/simulation2` 73개 파일 1,260개 테스트 통과, 변경 파일 ESLint 통과, `npm run build` 성공(기존 경고 4건), 브라우저 스모크 통과.

## 되돌리는 방법

이 기록과 gitlink만 담은 커밋을 되돌리면 우산 저장소가 이전 `f0fffed4` 프로젝트 커밋을 가리킨다. 고양 UAM 프로젝트 저장소의 커밋과 앱 저장소의 병합은 유지된다.
