- `projects/porthole/.git`: 디렉터리 → 파일(`gitdir: ../../.git/modules/projects/porthole`). `git submodule absorbgitdirs` 로 본체를 `.git/modules/projects/porthole` 로 옮겼다.

## 결정과 이유

- 원격 위치 `innopam/ws-jeju-porthole`(사용자 결정). 제안한 `innopam/porthole`, `inp-solution/porthole`, `garam-park/porthole` 대신 사용자가 이름을 정했다. ws 안 경로는 `projects/porthole` 그대로 둔다.
- URL 은 SSH 로 적었다. 다른 서브모듈이 모두 `git@github.com:` 형식이다.
- `branch = main`: `git submodule update --remote` 가 따라갈 브랜치. 다른 서브모듈처럼 `.gitmodules` 에 둔다.
- `absorbgitdirs`: 다른 서브모듈(`ops/dev0`, `jeju-ai-saas-fe` 등)은 `.git` 이 파일이다. 기존 폴더를 `submodule add` 하면 `.git` 이 디렉터리로 남아서 같은 방식으로 맞췄다.
- 서브모듈 첫 커밋 메시지에 AI 트레일러를 넣지 않았다(사용자 전역 지침).

## 되돌리는 방법

- ws 커밋 전: `git rm --cached projects/porthole` 후 `.gitmodules` 의 `projects/porthole` 항목을 지우고 `git add .gitmodules`. `.git/modules/projects/porthole` 를 `projects/porthole/.git` 로 되돌리려면 `projects/porthole/.git` 파일을 지우고 디렉터리를 옮긴 뒤 `core.worktree` 설정을 지운다.
- GitHub 저장소: `gh repo delete innopam/ws-jeju-porthole`. 지금 gh 토큰에는 `delete_repo` 권한이 없어 `gh auth refresh -s delete_repo` 가 먼저 필요하다. 웹 설정에서 지워도 된다.
