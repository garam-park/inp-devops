# AGENTS.md 에 worktree 위치와 규칙 추가 방법을 정함

- 날짜: 2026-10-22
- 요청: 새로 만들 worktree 는 `.ai-workflow/.worktrees` 에 만들도록 AGENTS.md 에 적는다. 새 규칙이 생기면 AGENTS.md 에 추가하고, 길면 `.ai-workflow/docs` 에 문서로 만들어 AGENTS.md 에서 참조한다.
- 이전 기록: [../21/09.jeju-ai-saas-decision-free-tasks.md](../21/09.jeju-ai-saas-decision-free-tasks.md) (worktree 를 ws 루트 `.worktrees/` 에 만들었던 작업)

## 배경

10-21/09 에서 서브모듈 worktree 4개를 ws 루트 `.worktrees/` 에 만들었다. 그 경로는 내 컴퓨터의 `.git/info/exclude` 에서만 무시돼, 다른 곳에서 받으면 추적되지 않은 파일로 보인다. 사용자가 위치를 `.ai-workflow/.worktrees` 로 정했다.

## 변경 내용

- `AGENTS.md`
  - '구조'에 `.ai-workflow/docs/`(참조용 긴 규칙 문서)와 `.ai-workflow/.worktrees/`(서브모듈 작업용 worktree, git 제외) 두 줄을 더했다.
  - '## worktree' 절을 새로 만들었다.
    - 위치: `.ai-workflow/.worktrees/<저장소 이름>/<브랜치>`. 브랜치의 `/` 는 `-` 로 바꾼다.
    - `git -C <서브모듈>` 에는 절대 경로를 준다.
    - 원격 브랜치를 기준으로 줄 때는 `--no-track` 을 붙인다.
    - 예시 명령을 넣었다.
  - '## 규칙 추가' 절을 새로 만들었다.
    - ws 의 새 규칙은 이 파일에 적는다. 서브모듈 하나에만 해당하는 규칙은 그 저장소의 AGENTS.md 에 둔다.
    - 몇 줄로 끝나지 않는 규칙(절차 · 표 · 예시)은 `.ai-workflow/docs/<짧은-영문-슬러그>.md` 에 쓰고, AGENTS.md 에는 한 줄 요약과 링크만 둔다.
- `.gitignore`: 없음 → `.ai-workflow/.worktrees/` 와 이유 주석.

## 결정과 이유

- '길면'의 기준은 사용자가 정하지 않았다. "몇 줄로 끝나지 않는 것(절차 · 표 · 예시가 필요한 것)"으로 적었다.
- 서브모듈 규칙 문장을 넣은 이유: 원칙의 "한 저장소만 볼 수 있는 사람이 필요한 규칙은 그 저장소 안에 둔다"와 겹치지 않게 하려고.
- `--no-track` 과 절대 경로는 사용자가 요청하지 않은 내용이다. 둘 다 예시 명령이 그대로 동작하는 데 필요해서 넣었다.
  - 10-21/09 에서 `origin/develop` 기준으로 만든 브랜치가 develop 을 추적하게 돼, 손으로 `--unset-upstream` 했다.
  - `git -C` 안의 상대 경로는 서브모듈 기준으로 풀린다.
- `.gitignore` 에 넣은 이유: 규칙이 다른 사람의 작업 공간에서도 맞으려면 로컬 `exclude` 로는 부족하다.
- 이미 ws 루트 `.worktrees/` 에 있는 worktree 4개는 '새로 만들 것'이 아니라 옮기지 않았다. 내 로컬 `.git/info/exclude` 의 `.worktrees/` 줄도 그대로 둔다(그 4개를 가린다).
- 커밋하지 않았다(요청 없음).

## 검증

- 버린 복제본(세션 임시 폴더)에서 예시와 같은 형태로 `git -C ../sub worktree add --no-track -b chore/x "$PWD/.ai-workflow/.worktrees/sub/chore-x" origin/develop` 를 돌렸다. worktree 가 그 경로에 생겼고, 브랜치에 추적 원격이 없다(`branch -vv` 에 `[origin/develop]` 없음). 확인 뒤 지웠다.
- `git check-ignore -v .ai-workflow/.worktrees/jeju-ai-saas-fe/x` → `.gitignore:7`.
- `markdownlint-cli2 AGENTS.md`(ws `.markdownlint-cli2.jsonc`) 통과.

## 되돌리는 방법

- `git restore AGENTS.md .gitignore` (커밋 전), 커밋 뒤라면 그 커밋을 revert 한다.
