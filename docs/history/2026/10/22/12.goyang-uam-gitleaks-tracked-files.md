- 날짜: 2026-10-22
- 요청: 결정 D14 에서 "B. lint:secrets 를 작업 트리 검사로" 를 골랐다.
- 이전 기록: [11.goyang-uam-porthole-layout-step1-3.md](11.goyang-uam-porthole-layout-step1-3.md)

## 배경

porthole 의 `mise run lint:secrets` 는 `gitleaks git` 으로 커밋 이력 전체를 본다. goyang-uam 이력에는 120건(20 커밋)이 걸리고, 이력은 이미 여러 clone 에 퍼져 다시 쓸 수 없다. `gitleaks dir .` 는 서브모듈 · svn checkout(27 GB)까지 훑어 1분 47초가 걸렸다.

## 변경 내용

goyang-uam 브랜치 `chore/porthole-layout`, 커밋 `fff728d0`(PR #165 에 추가):

- `mise.toml` `lint:secrets`: `gitleaks git --redact --no-banner` → 추적 파일(+ add 전 새 파일)을 `git ls-files -z --cached --others --exclude-standard | rsync -a --from0 --files-from=- ./ "$tmp"/` 로 임시 폴더에 복사한 뒤 `gitleaks dir "$tmp" -c .gitleaks.toml`. 0.5초.
- `.gitleaks.toml` `secret-file` 규칙에 `[rules.allowlist] paths = ['''\.env\.example$''']`. `deploy/local/.env.example` 은 값이 빈 본보기 파일이다.

## 결정과 이유

- `cpio -0 -p` 는 macOS 에서 아무것도 복사하지 않아(`--quiet` 미지원) rsync 로 바꿨다.
- 이력의 Notion API 토큰(`.opencode/opencode.json`, 커밋 `1ebfc2f5`)은 이 변경과 무관하게 폐기해야 한다. 사용자에게 알렸다.

## 검증

- `mise run lint:secrets`: 13.6 MB 검사, 28건(이전 29건에서 `.env.example` 1건 제외). 모두 D15 대상(원자료의 토큰 · 계정 정보 · 비밀번호, 시큐어코딩 예시, devhost `index.tsx`).
- `mise run lint` 는 그래서 아직 실패한다(markdownlint 는 통과). pre-commit 훅은 통과했다.
