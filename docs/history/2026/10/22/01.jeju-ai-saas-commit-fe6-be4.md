## 결정과 이유

- FE 는 10-21/09 의 추천대로 테스트와 수정을 두 커밋으로 나눴다. 다만 `useLayerSource.test.ts` 의 렌더 타이밍 테스트 1개는 수정 커밋에 넣었다. 같은 파일의 회귀 테스트와 import 한 줄을 같이 쓰고 있어서, 나누려면 working tree 에 없는 중간 import 줄을 지어내야 했다.
