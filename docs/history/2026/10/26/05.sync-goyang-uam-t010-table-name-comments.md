# 고양 UAM 저장소의 한글 테이블명 코멘트 반영 커밋을 우산 저장소 포인터에 반영

- 날짜: 2026-10-26
- 요청: 종료단계 DB 감리 지적사항 가운데 UAM 2번(한글 테이블명 설계/구현 불일치)을 합사 개발 DB 에 반영한다.
- 이전 기록: [고양 UAM 합사 DB 반영 커밋 포인터 갱신](./04.sync-goyang-uam-t010-ext-vworld-table.md)

## 배경

`projects/goyang-uam`(ws-goyang-uam) 의 T010 작업에서 DB 감리 지적 2번을 처리했다. 1번(`ext_vworld_layer_features`
구현 누락)은 앞선 기록에 이어 이번에 이어서 처리했다.

지적 2번은 사용자가 "설계 대비 컬럼명 불일치"로 알고 있었으나 실측 결과 달랐다. UAM 57개 테이블은 컬럼명까지 전부
설계와 일치했고(불일치 0건), UAM 에 해당하는 지적은 **한글 테이블명**이었다. 원인은 설계 문서 안의 두 칸이 어긋나
있었던 것으로, 우리 스키마의 `COMMENT ON TABLE` 값이 설계 문서 `GDP-PD-06 데이터베이스 설계서(07.UAM)` 의
'테이블 설명' 칸을 그대로 복사한 것이었고 7개만 그 설명이 '한글 테이블명'과 다른 이름으로 시작해 있었다.

프로젝트 저장소 커밋이 원격에 먼저 올라간 것을 확인한 뒤 우산 저장소 포인터를 갱신한다.

## 결정과 이유

- **설계 문서가 아니라 DB 를 고쳤다.** 상세 설명이 설계 문서 '테이블 설명' 칸에 그대로 남고, DB 를 고치면 컨소시엄
  SVN 공유 산출물 수정 절차도 메타데이터 현황표 수정도 필요 없기 때문이다.
- **lxdev·lxprod 는 손대지 않았다.** 감리 점검 대상은 합사 개발 DB 다. 두 환경은 LX 일정과 협의해 별건으로 반영하며,
  미반영 사실과 적용 대상 SQL 은 `gygo-database` 의 `deploy/lx/{dev,prd}/HISTORY.md` 에 메모로 남겼다.
- **기록은 서브모듈에 남겼다.** LX DB 배포 기록은 그 저장소의 `deploy/*/HISTORY.md` 가 기준이다.
