# 제주 프로토타입 UI를 SaaS 두 저장소에 적용했다

- 날짜: 2026-11-10
- 요청: 최신 프로토타입 화면·동작을 SaaS FE·BE에 반영할 수 있는지 확인하고 계획 후 진행한다.

## 배경

프로토타입 `0c5747a`의 SAR 1~5 자료와 화면이 SaaS의 기존 0~4 계약·화면과 달랐다. 사용자가 화면과 동작을 모두 이식하는 범위를 확인했다.

## 변경 내용

- `jeju-ai-saas-fe`: 최신 자료용 패널·조회·레이어·범례·상세·PDF 화면과 동작을 이식했다.
- `jeju-ai-saas-be`: 기존·최신 등급 축의 패키징·검증을 지원한다. API 타입도 다시 생성했다.
- 두 저장소에 `codex/t176-prototype-ui` 브랜치와 제품 작업 공간의 별도 worktree를 만들었다. 원본 develop 및 이 우산 저장소의 서브모듈 고정 커밋은 유지했다.
- 로컬 FE `127.0.0.1:5181`·메모리 API `127.0.0.1:18788`을 실행했다. 기존 미리보기는 유지했다.

## 결정과 이유

로그인·권한·서버 저장·반출 계약을 유지하며 최신 자료에 원본 화면을 적용한다. 기존 0~4·A~E 자료는 기존 해석을 유지한다. 구현 계획·증빙·상세 검증은 [제품 작업 기록](../../../../../projects/jeju-ai/docs/history/2026/11/10/06.prototype-ui-saas-parity.md)에 둔다.

## 검증

FE 단위 432개·BE API 225개·파이프라인 54개, 기존 Linux 브라우저 96개와 새 화면 6개 통과. 실제 최신 조회 6,324곳·CSI 4등급 89곳·5등급 0곳을 확인했다. 타입·코드/CSS lint·빌드·포맷 검사 통과. 운영 DB·스토리지 통합·배포는 수행하지 않았다.

## 되돌리는 방법

두 작업 worktree의 이번 변경을 되돌리고 새 로컬 프로세스를 종료한다. 기존 서버와 원본 develop은 유지돼 있다.

## 남은 일

커밋·push·운영 배포는 하지 않았다. 사용자 검토를 위해 작업 브랜치·worktree·미리보기를 보관한다.
