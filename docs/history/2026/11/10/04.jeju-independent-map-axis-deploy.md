# 제주 지도와 우측 조회 기준 분리 버전 재배포

- 날짜: 2026-11-10
- 요청: 프로토타입처럼 지도 레이어 선택과 우측 조회 탭을 독립적으로 동작하게 하고 재배포한다.
- 이전 기록: [앞선 배포](03.jeju-prototype-ui-deploy.md)

## 배경

SaaS에서는 지도 축을 우측 정렬 상태에서 파생해 양쪽 선택이 함께 바뀌었다. 사용자가 원본 프로토타입의 독립 선택을 요청했다.

## 변경 내용

- FE `2e5adae` → `9a08c417d29e48adf260c9a3c2c4ef9104d524a2`: 최신 1~5 SAR 화면에서 지도 축을 별도 상태로 관리한다. 지도 스타일·범례·등급 필터와 우측 분포·정렬·상세 기준을 각각 고른다.

## 결정과 이유

사용자 요청의 독립 선택을 FE에서 구현했다. 기존 CI·GHCR·Image Updater·Argo CD 경로로 배포했으며 태그를 수동 수정하지 않았다. 원본 작업 공간의 미게시 문서 커밋과 기존 스테이징은 보존하고 기록 전용 worktree에서 게시했다.

## 되돌리는 방법

FE 변경을 revert하여 develop에 게시하면 같은 배포 경로로 이전 동기화 동작이 복구된다. 필요하면 이 기록의 이전 값으로 우산 저장소 고정 커밋도 되돌린다. BE와 자료는 변경하지 않는다.
